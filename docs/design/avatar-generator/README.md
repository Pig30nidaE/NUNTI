# 목적지·경로 기반 눈티 생성기

2026-11-03. 운전습관 개선을 돕는 아바타 눈티 안에서, 사용자 담당인 여정 기반 생성 기능을 구현했다. 목적지와 확인한 경로에서 개인화된 눈티를 만들고, 캐릭터 ID·외형·음성 설정을 감정·피드백 모듈에서 이어서 사용할 수 있도록 보관한다. 운전 점수나 최종 코멘트를 새로 산정하지 않는다.

## 직접 실행

저장소 루트에서 `python3 scripts/run_avatar_generator.py`를 실행한다. 준비한 로컬 서버와 실제 Pleos Android 앱이 열린다. API 키는 필요 없다. [자세한 시험 안내](TESTING.ko.md)를 따른다.

## 구현한 경험

1. 내비 경로 사진 또는 0~1 좌표 JSON을 불러온다. 합성 내비 시험 이미지 세 개도 제공한다.
2. 원본 위에 추출한 선을 표시한다. 사용자가 확인해야 생성할 수 있다. 화면 좌표를 GPS·실제 거리·도로 특성으로 해석하지 않는다.
3. 목적지·그곳의 특성·방문 목적을 입력한다.
4. 경로가 줄어들며 완성 눈티 안의 **동일한 금빛 실 위치**로 이동한다. 그 선이 넓어지며 반투명 몸체가 드러난다. 렌더러가 PNG 회전까지 적용한 실 좌표를 모션에 전달한다.
5. 원래 경로와 생성된 눈티, 어떤 입력이 무늬·장식·재료에 반영됐는지 함께 보여 준다.
6. 완성된 PNG·SHA·입력·캐릭터 설정·목소리 설정을 자동 보관한다. 새 여정은 새 눈티를 만들며, 같은 요청의 재시도와 복원은 같은 결과를 쓴다.

디자인은 사용자가 선택한 C 방향의 반투명 기념 오브젝트를 따른다. [세 조형 비교](illustration/comparison-three-forms.png)에서 꽃잎 귀·조약돌·씨앗 구조를 비교했고, 맑은 재질·작은 발·작은 표정·금빛 경로실을 공통 조형으로 사용한다. [일러스트 구현과 한계](illustration/README.md), [서버 결과](server-result.md), [설계와 역할 경계](IMPLEMENTATION-CONTRACT.md)를 함께 본다.

`LOCAL_RENDER`는 여정 ID와 입력 전체로 매번 새 RGBA를 직접 그리는 로컬 렌더다. 고정 캐릭터 이미지 목록을 선택하지 않는다. 세 가지 조형과 명시 키워드 기반 재료를 사용하는 유한한 조형 문법이며, 임의의 서술을 이해하는 AI 원화 생성은 아니다. 전 세계의 시각적 유일성을 보증하지 않는다.

`IMAGE_API`는 별도의 명시 선택이다. 서버의 이미지 공급자 키·접근 모델·비용 설정이 있어야 표시된다. 로컬 디자인 PNG와 경로 그림을 이미지 모델에 함께 전달한다. 현재 어댑터는 OpenAI 이미지 API 한 곳의 키를 사용하며, 실제 계정·이미지 품질·청구·지연은 검증하지 않았다. AI 결과의 특징 설명은 제안된 모티브로 표시하며 실제 반영을 검증했다고 주장하지 않는다.

음성은 저장된 설명·속도·높이를 사용해 **기기의 기존 한국어 화자로 미리 듣는 기능**이다. 새 음색을 생성한 결과가 아니다. 재생은 누를 때만 시작하고 화면 이탈·주행 제한에서 중단한다. 준비된 한국어 엔진이 없으면 설치 안내를 보여 준다. 사용자 선호인 Anna 수준의 자연스러움이나 캐릭터별 새 음색은 검증하지 않았다. 기존 v2의 ElevenLabs 설계 음색과 소장품은 변경하지 않았다.

Android의 Debug와 release는 같은 main 생성 호스트를 사용한다. 차량에서는 실제 기어 P·정차·CarUxRestrictions 허가·foreground 조건으로 화면을 연다. 조건 미확인·주행·background에는 화면을 가리고 음성을 멈춘다. 일반 Android와 브라우저는 로컬 개발 시험 환경이다. 서버는 PC에서 실행하므로 APK 단독으로 이미지 생성을 수행하지 않는다.

완료 범위와 검증 증거는 [통합 결과](test-report.md)에 기록한다. 실제 NaviHelper 입력·Gleo 등록·실차·배포 서버·release 서명과 공모전 제출 완성은 별도다. 녹화와 스피커 녹음은 사용자의 명시적 요청 때만 한다.
