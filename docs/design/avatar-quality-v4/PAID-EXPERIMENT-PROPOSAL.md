# 실제 이미지 API 비교 실행안

사용자는 2026-11-03 품질 개선을 요청하며 유료 API는 사전 문의하도록 지시했다. 문의에 **원화 선택 후 결정**이라고 답했다. 현재 상태는 `DEFERRED_UNTIL_ART_SELECTION`이며 외부 생성 API를 호출하지 않았다. 아래는 후속 승인 판단을 위해 보관하는 범위다. 원화가 정해지기 전에 다시 실행 승인을 재촉하지 않는다.

- 공급자·모델 후보: OpenAI `gpt-image-2.5-sunburst` 이미지 편집.
- 요청당 결과: 1024×1024, medium, 투명 PNG 1장.
- 참조: 선택한 원화의 스타일 보드, 실제 확인한 경로, 대표 경로 구간과 몸의 부위 대응을 표시한 구조 지도.
- 비교 범위: 서로 다른 시험 여정 3개, 여정별 후보 2개, 총 최대 6회. 고정 캐릭터 카탈로그가 아니라 품질 비교 표본이다.
- 서버의 요청당 예약액: $0.30, 누적 예약 한도 $1.80, 호출 수 한도 6회.
- 실제 청구액은 계정의 현재 단가와 사용 토큰으로 결정된다. 예약액은 서버가 허용할 요청량의 경계이며 공급자 청구의 하드 리밋을 뜻하지 않는다. 실행 전에 실제 접근 모델·단가·입력 크기를 다시 확인한다.
- 타임아웃·응답 유실·실패 시 유료 POST 자동 재시도 없음. 이미지 결과가 불명확하면 중단하고 확인한다.
- 평가: 소장하고 싶은 정도, 목적지와 몸체의 연관, 원본 경로의 큰 굴곡이 읽히는 정도, 반투명 경계 품질, 채택당 전체 비용.
- 계정 준비: 사용자가 별도 OpenAI API 계정·키를 준비해야 한다. 키는 채팅이나 APK에 넣지 않고 로컬 서버 환경변수로 연결한다.

서버의 `paid_api_approved`와 실행기의 `--paid-api`는 기본 꺼짐이다. 기존 키와 가격 설정이 있더라도 기본 실행은 과금을 허용하지 않는다. 본문에 예산을 적은 것, 내장 도구로 컨셉 원화를 만든 것, 환경에 키가 있는 것 자체를 사용자 승인으로 간주하지 않는다.

현재 외부 이미지 API 호출은 0회다. 앱의 새 로컬 형상과 모션 개선, 제공된 내장 이미지 도구를 통한 원화 비교는 이 유료 실행안과 별도로 진행한다.
