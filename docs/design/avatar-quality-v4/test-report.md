# 눈티 v4 검증과 남은 범위

2026-11-03. 이 문서는 목적지·경로 기반 생성 기능의 외형·기하·보관 검증을 기록한다. 전체 제품 목표는 운전습관 개선을 돕는 눈티이며 [제품 기준](../../product/2026-hmg-app-challenge.md)을 유지한다.

## 사용자 판단

A/B/C 형태는 모두 괜찮다는 응답을 받았다. 과도한 입체감과 반투명 재질을 줄인 A2/B2/C2에 사용자가 “지금 표현이 적절함”이라고 답했다. 수정 원화의 렌더링 스타일은 승인됐고, 실제 로컬 AI 결과·탄생 모션·소장 의향의 최종 평가는 남았다.

## 구현과 확인

- 경로의 큰 굴곡·주축·진행 방향에서 몸의 흐름·꼬리·볏을 만들고, 목적지 특성에서 큰 구조를 계획한다. 새 여정 ID는 미세한 변주에 사용한다.
- 불투명한 파스텔 몸체와 매트 색면을 적용했다. PNG 배경의 alpha와 몸체의 반투명 재질을 구분한다.
- 경로에서 실제 닫힌 몸체 외곽이 자라는 탄생 효과를 적용했다. 중간 몸체의 강한 그라디언트·광택은 줄였다.
- 무료 로컬 이미지 모델은 실제 새 그림을 생성한다. 승인된 스타일과 이번 여정의 구조 지도를 별도로 참조한다. 고정 원화를 새 생성 결과로 반환하지 않는다.
- 모델 원본 RGB, 프롬프트, 구조·스타일 참조, seed·revision·시간을 보존한다. 외곽 배경을 제거한 RGBA에서 실제 외곽을 측정해 모션에 쓴다. 이때 경로의 몸체 투영은 창작된 기하 대응이며 의미 보존 검증 결과가 아니다.
- 얼굴 위치가 미확정이면 중간 얼굴 패치를 만들지 않는다. 실제 최종 PNG의 얼굴을 사용한다. 다수의 큰 객체나 배경 오류는 조용히 잘라 숨기지 않고 거절한다.

## 최종 실행 결과

| 검사 | 실제 결과 |
|---|---|
| 전체 backend | 241개 + 하위 검사 7개 통과 |
| Chrome 실제 입력·사진·보관·복원 | 14개 통과 |
| Pleos Android 빠른 모드 | 14개 통과 |
| Pleos Android 실제 로컬 AI·모션·재시도·복원 | 13개 통과 |
| 비동기 입력·경계 회귀 | 10개 통과 |
| 순수 모션 기하 | 10형상·13,013프레임 통과 |
| 실제 Chrome Canvas | PNG 10개·중간 자세 50개 통과 |
| 후처리 모듈 | 위 backend에 포함한 10개 통과 |
| 정적 검사 | 변경 backend 모듈·실행/취합 도구 Ruff 및 diff 공백 검사 통과 |

실제 앱의 해변 생성은 최종 `local-matte-face-2` 참조·프롬프트에서 **45.01초**, 512², 4step, MLX 보고 피크 3.49GB였다. 몸체 회색이 사라지고 파스텔 색면·양눈·물결과 꼬리가 드러나는 것을 직접 확인했다. 모델 원본과 후처리 RGBA의 SHA를 대조했고 최종 PNG는 투명 픽셀 171,638개·완전 불투명 픽셀 87,849개다. 어두운 배경에서는 원본 크림색 안티앨리어싱과 접지 그림자 일부가 남을 수 있다. 정밀한 의미 기반 매팅은 아니다.

첫 Android 시험에서 생성은 성공했지만 검사 스크립트가 빠른 모드의 완료 문구를 기다려 실패했다. AI용 문구를 검사하도록 도구를 수정한 후 **같은 요청을 재사용하여 추가 추론 없이** 모션·재시도·복원을 재검증했다. 첫 실패 로그도 보존했다. 총 로컬 추론은 초기 비교 3회·정원 앞면 보완 1회·최종 Android 해변 1회다. 정원 앞면 보완은 얼굴 가림을 줄였지만 회색 몸체가 남은 실패이며 최종 채택하지 않았다.

기존 APK의 공통 main 호스트에서 PC 서버의 v4 화면을 실제 사용했다. 이번 변경에는 Android 소스 수정·APK 재빌드가 없다. 주행 전환 정책의 새 시험이나 실차 검증을 추가했다는 뜻은 아니다.

[취합 결과](verification/delivery.json), [Android AI 검사](verification/local-ai-android.json), [실제 앱 정지 화면](verification/android-local-ai.png), [생성 PNG](verification/preview-local-ai.png)를 보존했다. 검사 당시 소스 SHA를 현재 파일과 대조해 취합했다. 문서 검사 99개와 조사 자료 구조 18개도 통과했으며 이는 이미지 품질 시험과 별도다.

재현 도구는 [UI 검사](../../../scripts/verify_avatar_generator.mjs), [기하 검사](../../../prototypes/avatar_generator/formation.test.mjs), [실제 Canvas 검사](../../../prototypes/avatar_generator/verify_formation.mjs), [결과 취합](../../../scripts/verify_avatar_quality_v4.py)이다. `--local-ai` UI 검사는 새 실제 추론을 실행한다. 같은 실행 결과를 검토할 때는 `--resume-request=<저장된 요청 UUID>`를 사용해 추가 생성을 피한다.

## 실제로 남은 것

임의 목적지·복잡한 경로의 의미 반영률, AI 경로 굽이의 정확한 보존, 모든 생성물의 얼굴 가독성·미적 품질은 검증되지 않았다. 얼굴이 잎에 가려진 정원 결과와 구조 지도 inset을 복사한 초기 해변 결과는 실패로 보존했다. 배경 제거를 통과해도 귀여움이나 얼굴 품질을 통과했다는 뜻은 아니다.

음성은 기존 기기 한국어 TTS의 설정 미리 듣기다. 매 눈티의 새 음색·Anna 재현은 이번에 구현하지 않았다. 실제 NaviHelper, 주행 이벤트·점수·최종 코멘트 연결, 실차, 운전습관 개선 효과와 제출용 서명 release는 남았다.

유료 외부 API는 사용자 응답 “원화 선택 후 결정”에 따라 보류했다. 실제 호출은 0회다. 로컬 AI는 현재 Mac에서 실행하며 운영 클라우드 비용을 무료로 가정하지 않는다. 동영상 녹화·스피커 녹음은 하지 않았다.
