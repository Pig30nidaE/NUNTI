# 눈티 v5 작업 기준

2026-11-03. 최신 사용자 피드백은 생성 효과를 더 화려하게 하고, 몸의 경로가 흉터·얼룩처럼 읽히지 않게 하며 일러스트를 발전시키는 것이다. 기존 불투명 파스텔 색면·얕은 매트 2.5D 기준을 유지한다. 전체 제품은 운전습관 개선을 돕는 눈티이고 이번 담당 범위는 목적지·내비 경로 기반 생성이다.

## 원인과 바꿀 경계

경로는 원본 사실과 창작 조형의 입력으로 보존한다. 최종 몸의 지도 선·봉합선·상처 무늬로 그리지 않는다. 큰 굴곡과 방향은 실루엣·꼬리·볏의 구조에 반영한다. 목적지 모티브도 몸에 얼룩을 칠하기보다 큰 형태와 자연스러운 부속 구조를 만든다. 원본 경로의 정확한 모양은 별도 미니맵에 남긴다.

초기 경로는 몸 밖의 빛·입자를 이끈 뒤 성장 초반 사라진다. 닫힌 몸체가 경로에서 실제 부피로 자라는 기하는 유지한다. 효과를 2~3개 비교한 뒤 선택한다. 완성 p=1은 효과 픽셀 0, 원본 PNG 그대로이며 reduced motion·차량 gate는 유지한다.

## 파일 소유

- root: 새 원화·스타일 자산, api.py의 capability/기본 스타일 경로, 실행·취합 도구, 문서·최종 실물 QA.
- illustration_v5: illustration.py·design_intent.py·해당 테스트. 표면 경로와 불규칙 색띠 제거, 기하 인과 유지.
- image_runtime_v5: local_model.py·image_api.py·관련 테스트. 구조 참조에서 spine·문자 제거, 깨끗한 표면 프롬프트, 최종 선택 스타일 참조, 무료 로컬 추론 해변·정원 2건 이내.
- motion_v5: formation.js·studio.js/css와 해당 재현 도구. 효과 비교·선 소멸·실측 외곽 기하 호환·실제 Canvas 확인.

## 유지와 검증

기존 소장품 이미지·ID·음성 설정을 변경하지 않는다. LOCAL_RENDER/LOCAL_MODEL/IMAGE_API 구분과 재시도 불변성을 유지한다. 새 모델 결과에 의미 반영률·얼굴 품질·소장 의향을 자동 승인하지 않는다. 실제 RGB·RGBA·참조·프롬프트·seed·revision을 보존한다.

표면 경로 없음의 계약을 메타데이터와 회귀 검사로 남긴다. 실제 route-only·destination-only 조형 비교, 대표 6개 빠른 렌더, 새 무료 AI 2개, 효과 3안의 정지 자세를 직접 확인한다. 전체 backend·실제 Chrome/Android·보관 복원을 새 소스에서 검증한다. 과금 외부 API는 0회, 유료 승인 보류 유지. 영상·스피커 녹음은 하지 않는다.
