# 사진 업로드 유실 수정

2026-11-04. 사용자가 v5 검증을 실행했을 때 Chrome 검사 10개 이후 사진 입력이 `NAVIGATION_SCREENSHOT`으로 전환되지 않아 중단됐다.

## 원인과 수정

생성 요청과 이미지 표시가 끝나 결과 버튼이 열렸지만, 앱은 보관함 목록 갱신까지 기다리는 동안 `generating=true`를 유지했다. 그 사이 새 여정에서 사진을 선택하면 FileReader는 완료됐어도 `extract()`가 생성 중이라는 이유로 반환했다. 실제 추출 POST가 없었고 사진을 선택한 의도가 유실됐다.

이제 생성·이미지 표시의 `try/finally`를 먼저 끝내고 보관함 갱신은 별도 작업으로 처리한다. 이전 갱신 작업의 `finally`가 새 사진 추출의 대기 상태를 덮을 수 없게 했다. 보관함 갱신 실패 안내도 해당 결과 화면을 보고 있을 때만 표시해 새 사진의 진행 안내를 가리지 않는다. 검사 대기 시간을 늘려 증상을 숨기지 않았다.

실제 HTTP 응답을 사용하는 Chrome 검사에서 보관함 응답을 지연시켜 수정 전 동일한 실패를 재현했다. 수정 후에는 이전 보관함 응답과 새 사진 추출 응답을 모두 지연시키고 보관함 응답을 실패로 바꿔도 사진 추출·대기 상태·안내·재확인 요구가 유지되는 것을 확인했다.
