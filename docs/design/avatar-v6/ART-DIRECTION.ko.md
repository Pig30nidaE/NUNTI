# 방문 목적을 입고 목적지를 소장하는 눈티

이번 개편은 경로의 색과 둥근 외곽만 달라지던 눈티에 **의상, 행동, 목적지 기념물**을 추가한다. 서울역에 출장을 가면 셔츠·넥타이·재킷과 두 다리 바지를 입는다. 을왕리에 수영하러 가면 수영복·수경·착용 튜브를 갖추고 발을 차거나 옆으로 떠 있는 자세를 취한다. 서울역에 수영하러 간다는 시험 입력에서도 활동은 수영으로 유지하고, 장소는 역 기념물로 따로 표현한다.

## 참고한 기법과 실제 적용

CLIP STUDIO PAINT의 캐릭터 입문 자료는 몸 비율과 의복의 외곽이 인상을 만들며, 일관된 색이 성격 표현을 돕는다고 설명한다. 이를 **몸형 → 의상 외곽 → 행동 → 소품 → 표정** 순서로 적용했다. 색만 바꿔 다양성을 주장하지 않는다. [캐릭터 아트 입문](https://www.clipstudio.net/en/characterart/beginners-guide/)

같은 제작사의 스타일 안내는 키·몸 비율·머리 모양·의상·액세서리로 실루엣을 구별하고, 그 실루엣을 인물의 배경과 연결하도록 권한다. 눈티에서는 수영 튜브와 발차기, 등산 배낭과 모자, 정장 바지와 서류 가방이 역할을 구별한다. 장소 기념물도 작은 인쇄 배지에서 **시계·기차·조개 모양 가방**으로 키웠다. [캐릭터 스타일 안내](https://www.clipstudio.net/en/characterart/art-style/)

의상 디자인 자료는 의복과 스타일링이 인물의 성격을 전달하는 수단이라는 점을 강조한다. 정장 라펠·셔츠 칼라·넥타이, 수영복 가장자리·수경, 미술 작업 앞치마·베레모를 별도로 그린 이유다. [의상과 실루엣으로 캐릭터 만들기](https://www.clipstudio.net/how-to-draw/archives/157653)

Disney Animation은 명료한 장면 구성, 타이밍, 준비 동작, 후속 동작으로 캐릭터의 성격을 표현한다고 설명한다. 생성 모션의 입력에는 단일 효과 이름 대신 목적별 `motionTheme`과 실제 캐릭터 외곽을 제공한다. 일러스트에서도 중심 행동과 얼굴을 가리는 소품을 피하고, 수영 동작의 기울기와 발차기 방향을 달리한다. [Disney Animation의 애니메이션 제작](https://www.disneyanimation.com/process/animation/)

위 자료에서 원칙을 참고했다. 외부 캐릭터 이미지를 복제하거나 제품에 포함하지 않았다. 로컬 도형 렌더와 별도로 생성한 구아슈 참고 원화는 서로 구분한다.

## 세 방향 비교

동일한 캐릭터 계획을 세 방식으로 그려 비교했다.

| 방향 | 차이 | 판단 |
| --- | --- | --- |
| STORYBOOK | 중간 굵기의 따뜻한 선, 큰 얼굴과 명료한 의상 | 기본 렌더로 선택 |
| FOLK_CHIBI | 작은 머리, 긴 몸, 굵은 선 | 의상은 읽히지만 작은 동반자 느낌이 약함 |
| SOFT_TOY | 큰 머리, 가는 선 | 얼굴은 귀엽지만 축소했을 때 의상 선이 약해짐 |

첫 비교 후 정장 하체가 원피스처럼 보이는 문제를 고쳤다. 바지 두 다리를 그린 뒤 재킷 길이를 줄였다. 수영은 손에 든 튜브에서 허리에 착용한 튜브로 바꾸고, 전용 동작 여섯 가지를 적용했다. 작은 장소 배지는 100픽셀 안팎의 기념 가방으로 바꿔 썸네일에서도 구별되도록 했다.

최종 대표 그림은 [목적지 기념물 비교](assets/art-prototypes/destination-keepsakes.png)에 있다. 세 방향의 첫 비교는 [표현 비교](assets/art-prototypes/comparison.png)에 남겼다. 현재 코드로 비교 그림을 다시 만드는 도구는 `scripts/render_avatar_art_studies.py`다.

## 생성 규칙

`journey_art.build_character_plan`은 목적지와 방문 목적을 독립적으로 해석한다. 알려진 역·해변 이름과 명시된 장소 종류를 사용하며, 미확인 장소는 `UNKNOWN`으로 남긴다. `놀이공원`을 `공원`보다 먼저 판별하고, `남산서울타워`를 `남산`과 구분한다.

방문 목적은 지원하는 13개 활동 역할로 정리한다. 활동을 확인하지 못하면 `purpose.resolution`을 `UNKNOWN`으로 남긴다. 이때 `role=EXPLORE`는 기존 화면과 호환되는 중립 여행 의상이며, 사용자가 탐험한다고 알아냈다는 뜻이 아니다.

명시된 활동에 맞는 의상과 소품을 선택하고, 새 여정의 seed가 몸형 12종, 의상 재단 5종, 자세, 소품, 표정, 비율과 방향을 조합한다. 완성 캐릭터 200개를 저장해 두고 고르는 방식은 아니다. 동일 요청의 재시도는 같은 계획과 그림을 복원한다.

경로의 진행 방향과 굽이는 귀의 기울기, 바깥 꼬리 곡선, 탄생 궤적에 반영한다. 경로선을 피부에 인쇄하지 않는다. `formation.contour`는 최종 PNG의 불투명 영역에서 측정한다. 따라서 생성 효과의 윤곽과 실제 캐릭터의 외곽을 같은 데이터로 연결할 수 있다.

목적지와 목적의 근거, 의상, 행동, 소품, 음성 역할은 `characterPlan`에 함께 저장한다. `structuralSignature`는 색과 여정 ID를 제외한 구조 조합을 식별한다. 이 값만으로 시각 품질을 합격 처리하지 않으며 실제 PNG와 실루엣을 따로 검사한다.

## 실제 로컬 AI에 전달하는 그림

로컬 AI는 `mlx-community/FLUX.2-Klein-4B-4bit`를 사용한다. 모델 revision은 `1cebb9b45c21ece14a42615b16bf5fa4de9b56da`, 현재 프롬프트 버전은 `local-journey-character-7`이다. 추론은 4단계이며 결과는 512×512 RGB PNG다. 계정 키나 유료 API 호출은 사용하지 않는다.

실제 30개 최초 검증에서 일부 목적지 가방이 일반 가방으로 바뀌었다. v7은 목적지 상징 10종 모두의 큰 외곽 형태를 명시하고, 의상·활동 소품·목적지 가방을 별개로 요구한다. HUG 자세는 빈손을 모으는 대신 지정한 물건을 안도록 설명하며, 야경도 배경 전체에 그리지 않고 의상과 기념품으로 표현한다. 최초 출력과 보강 출력은 덮어쓰지 않고 별도 폴더에 보존한다. 실제 충족 여부는 [결과 보고](RESULT.ko.md)의 이미지 검수를 따른다.

참조 순서와 크기는 다음과 같다.

| 순서 | 파일 | 실제 입력 | 역할 |
| --- | --- | --- | --- |
| 1 | `structure-reference.png` | 512×512 RGB | 해당 여정의 몸형, 의상, 행동, 선택 소품, 목적지 가방을 모두 그린 구조 참조 |
| 2 | `style-reference.png` | 256×256 RGB | 의상 없는 얼굴 기법 원화의 눈, 선, 매트 색면과 구아슈 질감 |

구조 참조는 `characterPlan`으로 그린 768×768 RGBA에 아이보리 배경을 합성하고 512×512로 줄인다. 이전의 회색 윤곽만 있는 참조와 달리 정장 바지나 수영 자세, 목적지 가방까지 실제 픽셀로 전달한다.

얼굴 참조 원본은 [style-face-technique.png](assets/style-face-technique.png)다. 배경을 합성한 다음 Lanczos로 최대 512×512, 다시 최대 256×256으로 줄인다. 이 두 단계는 실제 비교에 사용한 픽셀 처리와 일치하도록 유지한다. 원본에서 곧바로 256×256으로 줄이는 결과와는 픽셀이 달라지므로 회귀 검사에서 구분한다. 참조가 작아져도 출력 해상도는 512×512를 유지한다.

처음에는 의상을 입은 세 캐릭터 시트를 스타일 참조로 사용했다. 이후 원하지 않은 의상이 혼입되는 사례를 확인해 얼굴 기법만 제공하도록 바꿨다. 현재 프롬프트는 몸형·의상·자세를 첫 참조에서 가져오고 두 번째 참조에서는 표현 기법만 빌리라고 지시한다. 목적지 상징은 피부 무늬가 아닌 별도 기념 가방으로 명시한다. 서울역 시계, 수원역 기차, 해변 조개를 썸네일에서도 읽을 크기로 유지하도록 요청한다.

이 지시는 모델 입력 계약이다. 완성된 그림이 의상과 소품을 모두 지켰다는 자동 판정은 아니다. 입력 계획과 두 참조, 프롬프트, 모델 revision, seed, 결과 원본과 각 SHA-256을 함께 저장해 실제 결과를 대조한다.

## 배경 제거 근거

`flat-border-cutout-2`는 원본의 RGB 채널과 캔버스 크기를 보존하고 alpha만 만든다. 가장자리와 이어진 단색 배경을 먼저 제거한다. 이후 주몸 바로 아래에서 작은 분리 그림자 한 개를 식별할 수 있다.

그림자 제거에는 모든 조건이 필요하다. 몸의 가로 범위 안에 있어야 하며, 면적은 몸의 8%와 전체 화면의 2% 이하여야 한다. 가로세로비 4 이상의 평평한 타원이어야 한다. 배경 대비는 최대 32단계 이하여야 하며, 색이 크게 바뀌지 않는 감광과 중심보다 흐린 가장자리가 있어야 한다. 위·옆·멀리 떨어진 객체, 어두운 소품, 색이 있는 소품, 단단한 경계의 타원, 복수의 모호한 그림자는 이 예외로 지우지 않는다. 남은 큰 분리 객체는 계속 `MULTIPLE_LARGE_OBJECTS`로 거부한다.

서울역 출장·수원역 데이트·을왕리 수영의 실제 AI 원본 3장을 재합성 없이 재처리했다. 서울과 수원은 분리 그림자 제거가 없었다. 을왕리는 몸 아래 2,900픽셀의 그림자 한 개만 제거했다. 몸 면적의 5.77%, 가로세로비 7.82, 최대 배경 대비 22였다. 세 결과 모두 원본 파일과 RGB 채널을 보존했다. [재처리 보고서](../../../.local/avatar-v6/local-ai-final/cutout-v2-verification/report.json)와 [을왕리 합성 확인 그림](../../../.local/avatar-v6/local-ai-final/cutout-v2-verification/eulwangri-swim-visible.png)에 근거가 있다.

`sourceForegroundComponents`는 제거 전 객체 목록, `foregroundComponents`는 제거 후 목록이다. `removedGroundShadows`에는 제거 면적·위치·대비·가장자리 측정값을 기록한다. 이는 보수적인 픽셀 규칙이며 의미를 이해하는 분할 모델이 아니다. 얼굴·목적지 상징·경로 의미는 검증됐다고 표시하지 않는다.

## 확인 범위와 한계

세 목적지의 의상·행동 비교, 장소 가방의 실제 외곽 변화, 회전한 수영 캐릭터의 얼굴 위치, 원본 계획으로 PNG 픽셀을 재현하는 검증을 추가했다. 기존 경로 순서·불투명 몸체·투명 배경·피부 경로선 금지 검증도 유지한다.

현재 회귀 검사는 실제 구조 참조의 의상·가방 픽셀, 구조와 얼굴 참조의 순서·크기, 얼굴 원화의 두 단계 축소, 출장과 수영의 의상·소품 프롬프트를 검사한다. 별도 프로세스 어댑터 검사에서는 추론 실행 파일만 시험용으로 대체한다. 실제 4단계·512픽셀 명령, 참조 저장 순서와 해시, RGB 결과 검사, 배경 제거와 alpha 외곽 계산은 제품 코드를 실행한다. 이 검사는 모델의 그림 실력이나 실제 GPU 추론 성공을 대신하지 않는다.

GPU를 사용하지 않는 관련 회귀 검사는 저장소 루트에서 다시 실행한다.

```sh
PYTHONPATH=backend .worktrees/server/backend/.venv/bin/python -m pytest \
	backend/tests/test_avatar_design_intent.py \
	backend/tests/test_avatar_illustration.py \
	backend/tests/test_avatar_character_art.py \
	backend/tests/test_avatar_local_model.py \
	backend/tests/test_avatar_matte_cutout.py -q
```

정형 200개와 별도로 자연어 문장 30개를 작성해 부정·동의어·미확정 목적을 점검했다. `출장 아니고 휴식`은 휴식, `회의 취소돼서 카페`는 카페로 처리한다. `미팅인지 카페인지 아직 정하지 못했어요`는 `UNKNOWN`이다. 단순 키워드의 첫 일치를 사용하던 결과는 8개만 맞았고, 수정한 규칙은 30개를 모두 통과했다. 이 30개는 수정에 사용한 회귀 표본이며 일반적인 한국어 이해 정확도를 뜻하지 않는다. 문장과 기대 결과는 [자연어 회귀 명세](semantic-holdout.json)에 있으며, `scripts/verify_avatar_semantics.py`로 다시 검사한다.

모델 프롬프트는 의상·선택 소품·활동·자세를 별도로 기술한다. 예를 들어 노트북을 선택한 출장 눈티에게 서류 가방을 추가하라고 지시하지 않는다. 목적별 영문 표현과 실제 소품 명세는 `journey_language.py`에 있다. 이 언어 보강 전후에 기존 200개의 PNG SHA256, 이름, 활동 역할, 구조 식별자, 선택 소품이 모두 같은지도 확인했다.

200개 상황의 구조 중복과 실제 PNG 검사는 별도 배치 보고서를 기준으로 한다. 빠른 일러스트 200개, 실제 한국어 음원 200개, 별도로 실행한 AI 원화는 서로 다른 검증 집합이다. AI 원화의 최종 수량과 시각 검토 결과는 [결과 보고서](RESULT.ko.md)를 따른다. 유한한 조합으로 모든 미래 요청이 수학적으로 고유하다고 보장하지 않는다. 각 여정의 원본 이미지와 계획을 저장하므로 소장품 정체성은 유지한다.

로컬 렌더는 명시적 기법으로 의상과 구도를 조합한다. 전문 일러스트 모델의 질감과 세부 묘사는 별도 로컬 AI 생성 경로에서 확인한다. 자유 문장의 모든 의도나 부정을 이해하는 언어 모델은 이 규칙 분류기에 포함되어 있지 않다.
