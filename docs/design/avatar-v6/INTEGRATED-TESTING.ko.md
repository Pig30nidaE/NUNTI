# 생성한 눈티로 주행 시험하기

통합 코드와 기존 환경을 준비한 뒤 아래 순서로 시험한다. 에뮬레이터·서버를 작업 종료 때문에 자동 종료하지 않는다. 서버를 재시작하거나 APK를 업데이트하는 명령은 현재 실행을 갱신하므로 해당 작업을 승인한 경우에 실행한다.

## 앱 열기

최초 환경은 [기존 실행 안내](TESTING.ko.md)를 따른다. 현재 코드를 빌드해 반영하려면 저장소 루트에서 실행한다.

```bash
python3 scripts/run_avatar_generator.py --build --local-ai --navigation-api --restart-server
```

이미 반영된 서버와 APK를 쓰는 경우에는 앱에서 **눈티**를 연다. Virtual Console을 **P·속도 0**으로 맞춘다.

## 같은 눈티와 출발하기

1. **내 눈티**에서 기존 아바타를 선택하거나 새로 생성한다.
2. **이 눈티의 주행 음성 준비**를 누른다. 인사와 네 감정 대사를 보관하며 같은 캐릭터에서 다시 누르면 캐시를 사용한다.
3. **함께할 여정**에서 **실시간** 또는 **시험**을 선택한다.
4. **눈티와 함께하기**를 누른다. 생성된 같은 그림과 이름이 동반자 화면에 나타나는지 확인한다.

음성 준비 없이 출발할 수 있지만, 보관하지 않은 대사는 화면으로만 알린다. 시험 모드는 급제동 후 회복 시나리오를 약 48초에 걸쳐 재생한다. 이 모드는 실제 Console 입력이나 내비 위치를 재생하지 않는다.

## Virtual Console로 입력 보내기

1. [로컬 Virtual Console](http://127.0.0.1:8088)을 연다.
2. 기어를 **D**로 바꾸고 가속·제동을 조작한다.
3. 눈티 앱의 점수가 입력에 따라 변하는지 확인한다. 충분한 표본이 모이기 전에는 평가 불가가 정상이다.
4. **내비 열기**로 전환한 뒤 눈티로 돌아온다. 기록이 계속됐는지 확인한다.
5. **P·속도 0**으로 돌아온 뒤 **여정 마치기**를 누른다.
6. 점수, 평가 범위, 항목별 근거, 감지된 사건을 확인한다.

현재 속도에는 공개 Vehicle 2.3.2에 없는 실험용 직접 구독 경로가 포함된다. 내비의 경로 위 차량 이동은 별도 미검증이다. **내비를 열었다는 사실만으로 GPS가 연결됐다고 판단하지 않는다.**

## 반복 검증

```bash
python3 scripts/verify_integrated_journey.py --run
```

이 도구는 실제 앱의 시연·실시간 여정을 열어 확인하고 Console 값을 원복한다. 이미 진행 중인 여정이 있으면 중단한다. 녹화하지 않는다. 결과 파일의 `status`와 각 검사·복원 결과를 확인한다. 마지막 리포트는 생성 결과 화면의 **진행 중인 여정 · 마지막 리포트**에서 다시 연다.
