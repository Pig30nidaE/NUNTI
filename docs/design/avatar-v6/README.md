# 눈티 v6: 여정의 목적이 보이는 캐릭터

목적지·방문 이유·경로를 한 캐릭터의 외형, 의상, 소품, 탄생 연출과 한국어 목소리로 연결한다. [직접 시험하기](TESTING.ko.md)와 [검증 결과](RESULT.ko.md)를 먼저 확인한다.

## 생성 구조

1. 장소명과 사용자가 적은 특성에서 목적지 상징을 정한다. 서울역은 시계와 승차권, 수원역은 기차, 해변은 조개 형태의 기념 가방으로 표현한다. 이는 장소 지식과 명시한 특성에 따른 해석이며 지오코딩이나 시설 조회 결과가 아니다.
2. 방문 이유에서 역할·의상·행동을 정한다. 출장 의상은 목적지가 해변이어도 유지한다. 부정 표현과 일부 동의어를 처리하며, 모르는 뜻은 `UNKNOWN`으로 남긴다.
3. 새 여정 ID와 경로를 사용해 몸형·옷의 재단·자세·소품·표정·구도를 조합한다. 현재 조합 문법은 12개 몸형과 13개 목적 역할을 포함한다. 완성 캐릭터 목록에서 이미지를 고르는 방식은 아니다. 반면 무한한 새 기본 해부 구조를 만드는 문법이라고 주장하지도 않는다.
4. 빠른 모드는 이 계획으로 RGBA 일러스트를 그린다. AI 모드는 동일 계획의 완성 구조 참조와 별도 얼굴·질감 참조를 로컬 FLUX.2-Klein-4B 4bit에 전달해 새 그림을 만든다. AI의 실제 표현이 계획과 일치하는지는 결과 검토 대상이다.
5. 경로는 탄생 입자의 출발점과 귀·꼬리·몸짓 해석에 사용한다. 완성된 피부에 지도 선이나 흉터를 그리지 않는다. 목적별 물방울·꽃잎·티켓·별 연출이 끝나면 원본 그림만 남는다.
6. `characterPlan.purpose.role`을 Qwen3-TTS VoiceDesign 1.7B 8bit의 음성 지시로 바꾼다. 첫 듣기에서 새 한국어 음원을 합성하고 저장한다. 후속 문장은 이 합성 음원을 Base 모델의 참조로 사용할 수 있다. 실제 사람의 녹음을 복제하지 않는다.

## 보존과 실제 앱

같은 요청의 재시도는 같은 캐릭터로 이어진다. 보관 복원은 이미지나 음성을 새로 만들지 않는다. 생성 음성은 별도 소유자 범위 저장소에 한 번 연결하며 파일 해시가 바뀌면 재합성으로 숨기지 않는다. 첫 합성의 끝맺음·길이 검사에서 실패한 후보는 게시 전에 제한된 횟수로 다시 만든다.

Android는 인증된 WAV를 `MediaPlayer`로 재생한다. 실제 차량의 P·정차·화면 사용 허가와 앱 foreground 조건을 유지하고, 화면 이탈과 오디오 포커스 손실 시 중단한다. 앱의 이미지·음성 생성은 연결된 Mac 서버를 사용하며 차량 내부에서 모델을 실행하는 구조는 아니다.
