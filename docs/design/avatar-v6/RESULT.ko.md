# 눈티 v6 구현·검증 결과

2026-11-04. 목적지·방문 이유를 의상·소품·자세·한국어 목소리·탄생 효과로 연결했다. 사용자 요청에 따라 실제 로컬 AI 그림 검증은 30개로 줄였다. 완료한 빠른 일러스트 200개와 TTS 200개 결과는 유지한다. [직접 시험 안내](TESTING.ko.md).

## 완료

- 목적 우선의 캐릭터 계획, 12개 몸형과 13개 목적 역할의 의상·소품 조합, 목적지별 큰 기념 가방을 구현했다. 경로선은 피부에 그리지 않는다.
- 빠른 일러스트 PNG 200개를 실제 렌더했다. 전체 구성 200종, 몸형·의상 재단·주 소품만 비교한 구성 192종, 몸형·의상 종류 조합 99종이다. 색이나 해시 차이만으로 200종을 판정하지 않았다.
- 동일 목적지·목적에서 새 여행 10개는 실제 픽셀과 구조가 모두 달랐다. 동일 요청의 재시도는 PNG·metadata가 일치했다.
- 장소·목적 계약 200개와 자연어 회귀 30개를 검사했다. 자연어 중 3개는 미확정으로 남긴다. 이 표본의 통과가 모든 자연어 해석을 보장하지 않는다.
- Qwen3-TTS로 실제 WAV 200개를 생성했다. 고유 binding·파일 해시 200개, clipping 0개, 길이 4.72~12.24초다. 최초 194개 음원은 바이트를 유지하고, 종료 실패 4개와 과긴 발화 2개는 보강한 게시 전 재시도로 해결했다. 원본 실패 기록과 후보 음원은 보존했다.
- 같은 캐릭터의 첫 합성음을 Base 모델에 참조해 새 문장을 생성했다. 처음 수락한 음원은 캐시 복원 시 바꾸지 않는다.
- 최종 음원 200개를 독립 WAV 검사와 자동 전사로 확인했다. 원문을 전사 프롬프트로 주지 않았으며 정규화 문자 오류율은 8.42%였다. 28개는 청취 검토 대상으로 남았다.
- PNG와 WAV의 계획·이름·역할·해시 연결 200개가 일치했다. [200개 갤러리](../../../.local/avatar-v6/matrix/index.html)에 각 음원 재생 버튼을 연결했다.
- 목적별 티켓·물방울·꽃잎·별 등의 탄생 효과를 구현했다. 실제 Android WebView Canvas에서 200개 × 4시점, 총 800회 렌더했다. 입자의 입력 경로 연결과 완성 후 효과 제거를 확인했으며 최종 그림은 원본을 직접 그린 결과와 픽셀 차이가 0이다.
- 실제 Android UI의 목적별 생성·새 WAV 재생·완료·보관 복원·내비 화면 이탈 중단을 23개 항목으로 검사했다. 늦은 native 완료·실패 신호는 페이지와 재생 요청 식별자가 일치할 때만 반영한다.
- 늦은 이전 음성 이벤트가 새 음성을 끊는 문제와, 보관함 응답 순서가 최신 선택을 덮어쓰는 문제를 수정했다. 제어 경계 회귀는 음성 17개, 보관함 8개, 내비 입력 8개, 생성 실패 처리 7개다. 로컬 그림의 확정된 품질 거절 뒤에는 사용자가 같은 버튼을 눌러 새 그림을 시도할 수 있다. 결과가 불확실한 요청과 유료 요청은 임의로 새 요청으로 바꾸지 않는다.
- Android debug·release APK 빌드와 lint를 통과했다. 로컬 생성 서버·인증 미디어·현재 Pleos 호스트를 연결한다.
- 서버 아바타 회귀 205개와 하위 사례 104개, 관련 Python Ruff 검사를 통과했다. 실제 Android UI에서는 그림 역할뿐 아니라 출장·데이트·수영의 음성 역할까지 비교했다.
- 별도 실제 앱 통합 시험에서 저장된 OSRM 도로 경로와 ‘어린이 캐릭터가 해변에서 책 읽기’로 새 AI 그림과 5.92초의 새 한국어 WAV를 만들었다. 독서복·책·조개 가방을 확인했고, 명시적인 어린 캐릭터 지시를 합성에 사용했다. 생성·실제 Android 재생·보관함 복원·재합성 없는 재생의 32개 검사를 통과했다. 이 1건은 30개 표본과 따로 센다. 소리의 연령 인상·자연스러움은 사람의 청취 승인이 아니다.

## 실제 AI 30개 검증과 수정

기존 세 캐릭터 스타일 시트가 데이트 캐릭터에 수영모를 섞는 문제를 실제 출력에서 확인했다. 구조 참조를 먼저 두고, 의상 없는 얼굴·질감 기법 자료를 분리했다. 수정 후 서울역 출장의 정장·노트북·시계 가방과 수원역 데이트의 리본 코트·꽃·기차 가방을 확인했다.

을왕리 수영 그림은 분리된 바닥 그림자가 배경 제거의 다중 객체 검사에 걸렸다. 몸 아래의 작고 평평한 저대비 중성색 그림자 하나만 제거하도록 보강했다. 실제 원본 3장을 재추론 없이 다시 처리해 모두 통과했으며, 분리 소품·다른 캐릭터·모호한 그림자는 계속 거부한다.

구조 참조 512px는 유지하고 얼굴 기법 참조만 512→256px로 줄였다. 두 실제 비교에서 의상·표정·기념품의 읽힘을 유지하며 약 41초에서 32초로 줄었다. 최초 30개 평균은 32.08초였다. 입력 표본은 목적지 20곳·방문 목적 10종 각 3개·몸형 12종을 포함한다. 실제 AI가 12종의 동물 외형을 모두 충실히 그렸다는 뜻은 아니다.

최초 30개는 RGB 30개·배경 제거 29개·의상과 목적지 상징의 핵심 시각 기준 24개 통과였다. 1개는 밤하늘 배경, 5개는 목적지 가방의 누락·약화가 있었다. 원본과 실패를 `.local/avatar-v6/ai-matrix-final/`에 보존했다.

v7은 의상·활동 소품·목적지 가방을 분리하고, 10종 장소 상징의 외곽 형태와 빈 배경을 명시한다. 핵심 실패 6개를 같은 입력·seed로 다시 생성해 모두 복구했다. 붓이 떠 보이던 원인은 참조 그림에서도 손과 붓이 떨어져 있었기 때문이었다. 붓·연필·등산 스틱의 손잡이 좌표를 바로잡고 `10-art`를 한 번 더 생성해 손 접촉과 두 손을 확인했다.

최종 선택은 **30개 상황·30개 사용 가능한 RGBA·서로 다른 픽셀 30개·의상과 목적지 상징 검토 30개 통과**다. 실제 모델 실행은 최초 30회 + 지시 보강 6회 + 그립 수정 1회로 **37회**이며, 상황 수와 재시도 수를 구분한다. 최종 선택은 검증을 통과한 v6·v7 시도들의 조합이다. 원본, 선택 이유, 각 프롬프트·참조 SHA는 [최종 AI 갤러리](../../../.local/avatar-v6/ai-matrix-selected/index.html)와 `selection.json`에 보존했다. 사람의 디자인 승인을 받은 결과는 아니다.

세부 활동 소품은 명확 16개·부분 반영 9개·누락 5개이며, 동물형은 명확 26개·불확실 4개다. 스케치북·찻잔·케이크 등 세부 소품의 생성 편차가 남는다. 이를 핵심 의상·장소 판정과 별도로 [세부 감사 결과](../../../.local/avatar-v6/ai-matrix-selected/final-audit.json)에 기록했다.

손잡이 수정 후 빠른 일러스트 200개도 다시 렌더했다. 그림 8개와 그 그림의 측정 외곽만 바뀌었고 192개는 같았다. 캐릭터 계획·이름·입력·음성 계획 200개 및 WAV 200개의 해시는 유지했다. 최종 AI 30개도 실제 Android Canvas에서 4시점씩 120회 검사했고, 경로 입자 연결·완성 후 효과 제거·최종 원본 그림과 픽셀 차이 0을 확인했다.

## 미구현·미검증

- 실제 주행 이벤트에 따른 운전 점수·감정·음성 피드백, 실차 통합, 공모전 배포는 이번 생성 기능 시험 범위 밖이다.
- 200개의 서로 다른 WAV는 청감상 서로 다른 화자 200명이라는 증거가 아니다. 자연스러움·귀여움·Anna와의 품질 동등성은 미검증이다.
- 전사의 지명·가상 캐릭터 이름 오류를 TTS 발음 오류와 구분하는 청취가 남았다. 자동 전사 일치율로 자연스러움을 판정하지 않는다.
- 소장 의향과 운전습관 개선 효과는 사용자 평가가 필요하다. AI 시각 검토를 사람의 최종 디자인 승인으로 표시하지 않는다.
- 현대 SDK에서 전체 도로 polyline은 확인하지 못했다. 실제 목적지·현재 위치는 SDK에서, 전체 도로 형상은 별도 OSRM에서 가져온다. 두 경로의 일치와 SDK의 GPS 이동 반영은 [기존 내비 검증 한계](../navigation-integration/RESULT.ko.md)를 따른다.
