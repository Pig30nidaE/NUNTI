# 여정 캐릭터 제품·아트 독립 검토

2026-11-02. 검토 입력은 사용자 요구와 `docs/product/journey-character-brief.md`다. 이 문서는 구현 사실이나 합의된 wire 계약을 주장하지 않는다. 기존 코드는 검토하지 않았고 외부 생성 모델을 호출하지 않았다. 컨셉 시안 A/B/C와 C 수정안은 직접 열어 검토했다. 실제 음성과 동작은 평가하지 않았다.

사용자가 사려는 경험은 "이동할 때마다 다른 모습이 나오는 기능"보다 구체적이다. 내 여정에서 태어난 생명체를 만나고, 이번 이동의 기억을 그 캐릭터와 함께 보관하는 경험이다. 형태가 귀엽기만 하거나 목적지 색상이 반영되는 것만으로는 부족하다. 캐릭터를 따로 보여줬을 때도 간직하고 싶어야 하고, 나중에 다시 봤을 때 어떤 여정의 친구인지 떠올릴 수 있어야 한다.

## 최신 결정과 C 방향 검토

사용자는 C 반투명 기념 오브젝트를 선택했다. 제품 아트 방향은 C로 진행한다. 아래의 B 선호와 세 안 비교는 사용자 선택 전 독립 검토 기록으로 보존한다. 현재 진행 방향에 대한 권고는 C의 소장물 같은 매력을 유지하면서 여정마다 다른 생명체를 만들고, 작은 화면에서도 표정을 읽을 수 있도록 다듬는 것이다.

C의 강점은 맑은 몸 안에 이번 이동의 기념물을 간직한 듯한 느낌이다. 해안의 물결과 미술관의 흐르는 색층은 캐릭터 자체가 작은 기념 오브젝트처럼 보인다. 이 감각을 줄이고 다른 안에 가깝게 만들 필요는 없다. 반투명 껍질과 따뜻한 얼굴 중심의 관계를 정리하고, 몸의 구조와 재질을 일관되게 만드는 쪽으로 개선한다.

| 개선 대상 | C에서 유지할 것 | 다음 설계에서 바꿀 것 |
| --- | --- | --- |
| 여정마다 다른 몸 | 물결·산·소용돌이처럼 여정을 떠올리게 하는 형태 | 둥근 얼굴·손에 다른 껍질을 씌우는 방식에 머무르지 않는다. 해안형의 낮고 비대칭인 흐름, 산악형의 넓은 밑면과 층진 높이, 미술관형의 떠 있는 곡선처럼 몸의 길이·무게중심·외곽선이 다르게 보이도록 한다 |
| 개별 식별 특징 | 각 여정에서 온 한 가지 기억할 만한 특징 | 색·배경·작은 장식을 제거해도 몸을 구별할 수 있어야 한다. 물방울·잎·별 같은 작은 기호는 몸의 차이를 보조하며, 그 기호만 바뀌는 것을 새 캐릭터로 판정하지 않는다 |
| 반투명 재질 | 부드러운 투과광, 내부 색층, 장식품 같은 깊이 | 얼굴 뒤에는 충분히 불투명한 밝은 중심을 유지하고 눈·입은 어둡게 분리한다. 외곽과 내부 반사를 동시에 밝게 만들어 윤곽이 지워지지 않도록 명암을 정한다 |
| 산악형의 일관성 | 산봉우리·지층·새싹의 의미와 세로로 읽히는 형태 | 현재의 넓은 불투명 이끼 표면을 반투명 수지·유리 같은 층과 내부의 초록색 지층으로 바꾼다. 작은 돌이나 새싹은 부분적인 불투명 요소로 남길 수 있지만 얼굴 주변과 몸 대부분을 덮지 않는다 |
| 생명체 같은 교감 | 따뜻한 얼굴, 둥근 손, 호감 가는 미소 | 웃는 정지 장식품에 머물지 않도록 듣기·말하기·휴식 상태를 같은 캐릭터로 확장한다. 표정마다 얼굴 중심의 크기나 위치가 달라져 다른 캐릭터처럼 보이지 않게 한다 |

위 표는 C 선택 직후 제안한 개선 지시다. 이후 PM이 만든 C 수정안은 아래와 같이 별도로 직접 확인했다. 정적 시안의 인상과 차이를 검토한 것이며, 작은 화면·레이어·움직임·음성을 검사한 결과는 아니다.

### C 원안에서 수정안으로 확인한 변화

`docs/design/journey-characters/concepts/c-luminous-v2.png`를 직접 열었다. 원안의 산악형을 덮던 불투명 이끼가 사라지고 반투명 초록·금색 층 안에 지형과 길이 들어갔다. 세 캐릭터가 같은 재질 세계에 속한다는 인상이 원안보다 명확하다. 해안형은 낮고 길게, 산악형은 높고 좁게, 미술관형은 넓은 별 형태로 보여 몸의 비례 차이도 커졌다. 각 얼굴의 따뜻한 바탕과 어두운 눈·입은 이 밝은 배경의 큰 정지 이미지에서 읽힌다.

남은 점은 원안과 같다. 둥근 얼굴 중심을 감싼 몸이 실제 축소 실루엣에서도 구별되는지, 내부 길과 색층이 작은 화면에서 형태를 방해하지 않는지 확인해야 한다. 밝은 외곽과 반사광은 다른 배경에서 다시 봐야 한다. 산악형은 현재의 닫힌 눈 표정 하나뿐이라 같은 얼굴의 듣기·말하기 상태를 아직 판단할 수 없다. 이 수정안도 배경을 포함한 단일 정지 PNG다. 실제 투명 레이어, 깊이 분리, 표정 세트, 움직임, 캐릭터별 음성의 완성을 뜻하지 않는다. 내부 길은 창작 모티브로 보이며 실제 주행 궤적을 검증했다는 근거도 아니다.

이번 업데이트는 C 선택을 반영한 검토·지시 문서다. 새 모델 호출, 이미지 편집, 자산 제작이나 기능 변경은 하지 않았다. 운전습관 개선은 여전히 별도 행동 실험이 필요한 제품 가설이다.

## 생성 방식 비교

| 방식 | 얻는 것 | 놓치기 쉬운 것 | 권장 역할 |
| --- | --- | --- | --- |
| 순수 규칙 생성 | 빠른 생성, 동일 요청 복원, 일정한 표정과 동작 품질 | 같은 몸에 모자·색만 바꾼 캐릭터가 쌓인다. 경우의 수가 많아도 사용자는 다른 생명체로 느끼지 않을 수 있다 | 초기 프로토타입과 오프라인 대체, 검증된 파츠·rig의 조립 |
| 매번 자유 생성 | 예상 못한 형태와 재질, 넓은 탐색 범위 | 세계관이 흔들리고 귀여움의 편차가 커진다. 표정과 동작으로 확장하기 어려운 그림도 나온다. 생성된 외형과 목소리의 연결이 약해질 수 있다 | 초기 아트 탐색과 후보 만들기 |
| 아트디렉션 제약형 생성 | 새 몸과 실루엣을 만들면서 표정, 조명, 재질 표현, 음성의 문법을 유지한다 | 규칙이 지나치게 촘촘하면 다시 조합형 스킨이 된다. 품질 판정과 재생성 정책이 필요하다 | 제품의 주 생성 방식 |

아트디렉션 제약형 생성을 강하게 추천한다. 몸의 구조, 비율, 실루엣, 촉감, 이동 모티브, 성격은 여정마다 창작한다. 얼굴의 가독성, 표정 문법, 카메라, 조명, 렌더링 품질과 음성 후보의 범위는 감독한다. 자유롭게 만드는 영역과 일정하게 지킬 영역을 나눠야 한다. 귀여움을 모델의 우연한 출력에 맡기지 않으면서도 매번 새 캐릭터가 태어날 수 있다.

최종 이미지 한 장은 완성 판정이 아니다. 같은 캐릭터의 정면·3/4면, 작은 크기, 주요 표정, 짧은 동작, 실제 목소리까지 통과한 묶음이 제품 캐릭터다. 품질을 통과하지 못한 생성은 컬렉션에 확정하지 않는다. 생성이 끝나지 않아도 사용자가 출발할 수 있어야 한다.

## 애착을 만드는 반복 경험

1. 출발 전에 목적지·경로·방문 목적의 의미를 모아 캐릭터가 태어난다. 사용자는 짧은 탄생 소개와 목소리로 친구를 만난다. 생성이나 선택 때문에 출발이 늦어지지 않는다.
2. 이동 중에는 허용된 짧은 동행만 한다. 수집 조작이나 외형 평가를 요구하지 않는다. 캐릭터의 표정·말투는 관심을 끌기 위해 점점 강해지지 않는다.
3. 도착 후 캐릭터에게 이번 여정의 기억이 남는다. 검증된 사실이 있으면 구체적인 긍정 행동을 돌아본다. 운전 데이터가 없으면 평가를 만들지 않는다.
4. 주차한 상태에서 컬렉션을 다시 만나고, 캐릭터의 목소리와 여행 기억을 꺼내본다. 다음 이동의 이유는 캐릭터를 살려두거나 희귀 보상을 얻기 위한 의무가 되어서는 안 된다.

캐릭터의 존재와 애정은 운전 성적에 종속시키지 않는다. 나쁜 점수 때문에 캐릭터가 아프거나 사라지면 사용자는 피드백을 피하고 싶어질 수 있다. 장거리, 더 잦은 이동, 과속, 위험 이벤트, 연속 접속을 희귀도·미모·애정의 조건으로 쓰지 않는다. 안전한 행동에 대한 확인과 여정의 추억이 쌓이는 구조를 시험한다.

## 수용기준 초안

아래 수치는 모두 초기 미검증 가설이다. 출시 기준으로 확정하지 않았으며 사용자 평가와 실제 기기 검증 후 조정해야 한다. 디자인의 귀여움과 실제 운전습관 개선은 서로 다른 검증 대상이다.

| 검토 대상 | 확인 방법 | 초기 통과 가설 |
| --- | --- | --- |
| 정말 다른 새 캐릭터 | 색·소품·배경을 제거한 실루엣을 비교한다. 다른 경로와 같은 경로의 다른 여정도 포함한다 | 평가자의 80% 이상이 "같은 캐릭터의 스킨" 대신 "다른 캐릭터"로 구분한다. 몸의 구조·비율·형태·재질 중 둘 이상에서 실질적 차이가 있다 |
| 귀여움 | 여행 설명 없이 같은 크기로 보여주고 평가한다. 얼굴만 확대하지 않고 실제 전체 크기도 본다 | 5점 척도에서 귀여움·만져보고 싶은 느낌·표정의 호감도 중앙값이 각각 4점 이상이다 |
| 소장욕구 | 같은 노출 시간 뒤 각 캐릭터를 남기고 싶은지 독립 질문한다. 별도로 일부만 남기는 상대 비교와 자유 응답을 한다 | 독립 질문에서 대표 캐릭터 각각에 대해 참여자의 70% 이상이 "내 컬렉션에 남기고 싶다"를 택한다. 상대 비교의 선택 이유가 색 차이·희귀도뿐으로 수렴하지 않는다 |
| 개별성 | 캐릭터를 본 다음 여행과 성격을 맞추거나 회상하게 한다 | 다음 날에도 참여자의 70% 이상이 자신의 캐릭터와 해당 여정의 연결을 기억한다. 이 수치는 기억 실험을 거치지 않은 가설이다 |
| 같은 세계의 친구 | 서로 다른 실루엣의 캐릭터를 섞어 세계관이 같은 그룹을 묶게 한다 | 개별성을 유지하면서 참여자의 80% 이상이 같은 컬렉션의 캐릭터로 묶는다 |
| 표정 가독성 | 실제 화면 크기에서 무음으로 차분함·듣기·말하기·기쁨·휴식을 구분한다 | 핵심 상태 구분이 80% 이상이다. 48px 썸네일에서는 정체성, 실제 표시 크기에서는 표정과 입 움직임을 별도 확인한다 |
| 2.5D의 일관성 | 정면과 3/4면, 몸의 접지 그림자, 눈·입 위치, 표정 전환을 본다 | 그림자를 떼어도 몸의 볼륨이 읽히고, 시점·표정 변경 때 의도하지 않은 납작함이나 형태 붕괴가 없다. 투명 재질에서도 얼굴이 사라지지 않는다 |
| 외형과 TTS의 연결 | 같은 문장을 여러 후보 음성으로 듣고 외형과의 어울림·한국어 명료도를 평가한다 | 외형·성격과의 어울림 중앙값 4/5 이상을 가설로 둔다. 캐릭터 안에서는 문장이 달라져도 같은 친구로 들려야 한다. 현재는 청취하지 않았다 |
| 재생과 복원 | 동일 생성 요청의 재시도·reroute·재시작 후 자산과 음성 정의를 비교한다 | 이미 확정한 캐릭터와 목소리를 보존한다. 다음 여정에서는 새 캐릭터가 생길 수 있다 |
| 출발·도착 경험 | 생성 중·오프라인·오류 상황으로 실제 흐름을 진행한다 | 출발과 로컬 안전 정책이 생성 작업에 막히지 않는다. 새 캐릭터를 아직 받지 못했다면 그 상태를 솔직하게 알린다 |

평가는 합성 여정으로 시작한다. 도심 출근, 해안 휴식, 숲 산책, 도심 야간 방문처럼 목적지·경로·목적이 다르게 조합된 사례와 동일 경로의 재방문을 포함한다. 각 방향에서 가장 잘 나온 한 장만 비교하면 생성 품질의 편차를 놓치므로, 같은 조건에서 여러 번 생성한 후보를 함께 검토해야 한다.

## 자주 생길 실패와 판별법

| 실패 | 드러나는 모습 | 수정 방향 |
| --- | --- | --- |
| 스킨을 새 캐릭터로 포장 | 색·모자·소품을 지우면 모두 같은 몸이다 | 몸의 구조와 실루엣을 생성 대상으로 끌어올린다 |
| 랜덤 디테일을 개성으로 오인 | 이름과 장식은 많지만 작은 화면에서 구별되지 않는다 | 가장 기억할 만한 형태 특징 하나를 먼저 정하고 세부 요소를 줄인다 |
| 귀여운 얼굴만 있고 생명체가 없음 | 얼굴을 가리면 볼륨·촉감·몸짓의 매력이 없다 | 얼굴 없는 상태에서도 만져보고 싶은 몸을 검토한다 |
| 반투명이 가독성을 해침 | 밝은 배경에서 눈·입과 실루엣이 사라진다 | 얼굴 주변 불투명도와 윤곽을 유지하고 밝고 어두운 배경을 모두 본다 |
| 봉제 표현이 시판 인형과 지나치게 닮음 | 소재만 봉제이고 여정의 개별성이 없다 | 고유한 몸 구조와 여정에서 온 핵심 특징이 먼저 있어야 한다 |
| 동물·성격의 반복 | 모델이 귀여움을 큰 눈의 토끼·고양이·콩 몸으로만 해석한다 | 후보군의 형태 분포를 기록하고 반복되는 구조를 다음 생성의 제약에 반영한다 |
| 목적지가 장식 하나로 환원 | 바다는 조개, 산은 잎 모자만 반복된다 | 물의 움직임·지형의 곡선·방문 목적처럼 형태를 바꾸는 의미를 사용한다 |
| 여정과 억지로 연결 | 사용자가 설명을 들어도 왜 내 여행의 캐릭터인지 모른다 | 창작 모티브를 짧게 설명하고 실제 사실과 상상을 구분한다 |
| 목소리가 매번 바뀜 | 새 문장을 말할 때 다른 친구로 들리거나 과장된 톤만 남는다 | 캐릭터별 voice recipe와 허용 범위를 보존하고 실제 한국어 문장으로 듣는다 |
| 소장욕구가 FOMO로 변질 | 만료·연속 접속·희귀 뽑기를 위해 불필요한 이동을 한다 | 보유 캐릭터의 지속성과 여행 기억을 가치로 삼는다 |
| 안전 행동이 희귀도 조건으로 바뀜 | 평가 오류 때문에 덜 귀여운 캐릭터를 받았다고 느낀다 | 외형의 기본 매력과 캐릭터의 존재를 점수에서 분리한다 |
| 효과를 성급하게 주장 | 호감도 설문이 좋았다는 이유로 운전습관 개선을 선언한다 | 실제 행동 실험을 별도로 설계하고 관측 범위와 불확실성을 보고한다 |

## 운전습관 개선 검증의 경계

귀엽고 간직하고 싶은 캐릭터가 다시 돌아보고 싶은 마음을 만들 수 있다는 것은 제품 가설이다. 그 마음이 운전습관을 개선하는지는 아직 확인하지 않았다. 화면·음성에 대한 호감, 여정 기억, 컬렉션 재방문, 실제 운전 행동을 각각 측정해야 한다.

후속 실험에서는 동일한 운전 피드백을 주는 조건과 캐릭터가 그 피드백을 함께 전달하는 조건을 비교할 수 있다. 관측한 운전 상황, 노출량, 출발 전·도착 후 사용 조건이 비슷해야 해석할 수 있다. 피드백 내용과 행동 지표의 소유·정의는 기존 담당의 확인이 필요하다. 외부 담당 및 payload 조율은 현재 보류다. 행동 효과의 크기나 실험 기간은 이 검토로 확정하지 않는다.

## 초기 시안 독립 비교 기록

| 기준 | A 말랑 조형 | B 봉제 | C 반투명 |
| --- | --- | --- | --- |
| 귀여움 | 짧은 팔다리와 볼·눈 비율이 편안하다. 오른쪽의 비대칭 실루엣에 장난기가 있다 | 가장 먼저 안아보고 싶다. 작은 코, 수놓은 입, 볼의 털이 생명체의 온기를 만든다 | 맑은 얼굴과 둥근 손이 사랑스럽다. 유리 기념품의 반짝임이 먼저 보인다 |
| 몸의 차이 | 낮고 긴 해안형, 세로로 선 산악형, 넓게 퍼진 미술관형의 차이가 가장 명확하다 | 귀·꼬리·날개가 잘 구별된다. 다만 소품과 외곽 장식을 지우면 둥근 몸·배색 얼굴의 반복이 남을 가능성이 있다 | 물결·산·소용돌이 외곽은 다르다. 안쪽 얼굴과 손은 같은 둥근 생명체를 다른 재질로 감싼 인상이 강하다 |
| 세계관 | 무광 조형 재질과 얼굴 문법이 세 캐릭터에서 일정하다 | 털, 펠트, 바느질, 눈의 광택이 한 봉제 컬렉션으로 묶인다 | 해안과 미술관은 반투명 광택이 가깝다. 산악의 불투명 이끼 표면은 다른 시리즈처럼 보일 여지가 있다 |
| 표정의 읽힘 | 얼굴 대비가 좋고 입 모양이 보인다. 위를 보는 눈이 많아 정면 교감은 추가 확인이 필요하다 | 세 캐릭터 모두 웃음이 바로 읽힌다. 실제 축소 화면에서는 작은 코·자수와 털의 손실을 봐야 한다 | 얼굴 주변의 따뜻한 불투명 면이 현재 배경에서는 잘 보인다. 몸의 밝은 윤곽과 내부 반사는 배경이 바뀌면 손실될 수 있다 |
| 소장욕구 | 말랑한 피규어 세트를 떠올리게 한다. A 중에서는 해안형이 가장 독립적인 생명체처럼 보인다 | 세 안 중 가장 강하다. 사진 속 인형을 책상이나 가방에 두고 싶은 느낌이 있다 | 스노볼·아트 토이처럼 특별한 여정을 기념하는 물건의 매력이 크다 |

사용자 선택 전 독립 검토에서는 B를 정서적 매력의 주력 후보로 권했다. 털과 봉제선이 단순한 고해상도 장식으로 끝나지 않고, 손에 쥐고 싶은 촉감을 만든다는 판단이었다. A는 새 캐릭터의 몸을 만드는 기준으로 가장 좋은 비교 대상이라고 보았다. 제작 편의보다 사용자가 강조한 소장욕구를 먼저 검토하자는 취지였다. 이 판단은 한 검토자의 취향 기록이며, 이후 사용자가 선택한 C 방향을 변경하는 권고가 아니다.

세 안은 모두 도착지 모티브가 읽힌다. 경로와 방문 목적이 몸에 어떻게 다르게 반영됐는지는 이 한 장으로 확인할 수 없다. 해안은 조개나 파도, 산악은 잎과 산봉우리로 곧바로 번역되어 있어, 같은 목적지를 다른 목적으로 재방문했을 때도 다른 캐릭터가 나오는지 추가 사례가 필요하다. 세 안 모두 표정은 행복에 집중되어 있다. 듣기·말하기·휴식 상태, 3/4면 전환, 작은 표시 크기, 애니메이션과 실제 음성 정체성은 미검증이다.

선택 전에는 B의 봉제 재질과 얼굴 문법을 유지하되 조개·잎·팔레트·날개 같은 소품과 부착물을 제거한 세 캐릭터를 만드는 수정을 제안했다. 낮고 긴 몸, 서 있는 몸, 비대칭으로 퍼진 몸처럼 몸 자체로 다른 생명체가 되는지 보려는 제안이었다. 이 B 수정안은 현재 진행 지시가 아니다. 소품을 제거한 실루엣으로 새 캐릭터인지 검증한다는 원칙만 최신 C 검토에도 적용한다. 이번 검토에서는 모델 재호출이나 이미지 편집을 하지 않았다.
