# 상황별 눈티와 주행 리포트 확인하기

Pleos 에뮬레이터를 P단으로 두고 시작한다. [구현·검증 기록](CONTEXT_V4_DELIVERY.md)에 확인 범위와 비용이 있다.

1. 프로젝트 폴더에서 서버와 앱을 실행한다.

   ```sh
   cd /Users/pig30nidae/NUNTI
   python3 scripts/run_avatar_generator.py --paid-api --navigation-api
   ```

2. **다른 길 고르기**에서 목적지와 방문 목적을 입력한다. **면접·출근**, **병원**, **축구 직관**으로 의상을 고를 수 있다. 실제 경로가 필요하면 현대 내비에서 목적지를 정한 뒤 **내비 목적지 불러오기**를 누른다.
3. 기분을 선택하고 **오늘의 옷을 새로 만들기**를 켠 뒤 **눈티 만들기**를 누른다. 새로운 입력에는 API 비용이 발생한다. 같은 입력과 버전은 저장된 결과를 사용한다.
4. 결과 화면의 눈티를 터치한다. P단에서 표정과 반응을 확인한다. **움직임 줄이기**를 켜면 장식 동작이 멈춘다.
5. **여정 기록**에서 **운전 습관 연습 · 약 30초**를 선택한다. 창을 닫고 **함께 출발**을 누른다.
6. 약 30초 후 **여정 마치기**를 누른다. 리포트의 경로 핀과 이벤트 목록을 확인한다. **점수 산정 기준**에서 각 항목의 비중과 기준을 연다.

실제 차량 신호를 확인할 때는 5번에서 **실제 차량 신호**를 선택한다. 처음 나타나는 위치 권한 요청을 허용한다. 버추얼 콘솔에서 D단과 속도·핸들·브레이크를 조작한 뒤, 속도를 0으로 낮추고 P단에서 여정을 마친다. 현재 에뮬레이터는 D단에서 앱 화면을 차단하지만 기록은 계속한다.

GPS까지 자동 재생하는 확인 명령은 다음과 같다. 실행 중인 여정이 없는 상태에서 사용한다. 스크립트는 기존 정장 눈티를 재사용하며 새 이미지를 결제하지 않는다.

```sh
node scripts/verify_nunti_context_live.mjs artifacts/nunti-context-v4/manual-live
```

이 명령에는 로컬 서버, 연결된 Pleos 에뮬레이터, 버추얼 콘솔과 `.local/navigation-integration/live/seoul-plan.json`이 필요하다. 실행 후 원래 차량 설정과 GPS를 복원한다. 결과는 지정한 폴더의 `verification.json`에 저장된다.
