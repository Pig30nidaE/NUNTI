# 눈티 리파인 기준

2026-11-09 · identity-refine-v1 · 검토용 시안

고정 참조는 `docs/design/avatar-v6/assets/nunti-base-character.png`의 상단 전신 원화다. 프로젝트의 점수 모듈과 로컬 모델이 이 파일을 기준으로 사용한다. 별도의 최종 승인 기록은 확인되지 않았다.

큰 둥근 후드와 짧은 몸, 길이가 다른 두 새싹, 한쪽으로 흐르는 크림색 앞머리, 갈색 타원 눈과 작은 입을 유지한다. 눈의 상대적 크기와 간격을 고정하고 눈꺼풀·눈썹·입으로 감정을 표현한다. 정면 기준 스카프 매듭과 파란 배지는 화면 오른쪽, 가방은 화면 왼쪽에 둔다. 각도가 바뀌어도 해부학적 부착 위치를 따른다.

A는 부드러운 매트 입체감을 남기고 직물 무늬와 주름, 작은 버클과 신발끈을 줄인다. B는 넓은 색면과 얕은 명암, 가는 유색 윤곽으로 같은 인물을 정리한다. 아이보리·민트·미스트 블루·피치·갈색을 공통으로 사용한다. 외부 캐릭터를 모방하는 지시는 사용하지 않는다.

각 안은 정면·3/4·측면과 기본 표정, 차분함·호기심·걱정·놀람·안도·기쁨의 감정 6종을 포함한다. 64 px에서 새싹·후드·얼굴이 구분되는지, 128 px에서 표정과 배지가 읽히는지 평가한다. 원화와 생성 시트를 동일한 보드에 배치해 비교한다.

생성 방식은 연결된 내장 image_gen이다. 별도 API 키를 사용하는 유료 API 호출은 0회다. 내장 도구의 계정별 크레딧 사용량과 금액은 노출되지 않는다. 결과는 사람의 선택 전까지 검토용 자산으로 관리한다.
