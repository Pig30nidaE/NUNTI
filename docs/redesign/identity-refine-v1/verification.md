# 리파인 검토 기록

2026-11-09 · 최종 시트 A v3 / B v4 · 정적 시안 평가

## 확인한 결과

| 기준 | A | B | 판단 |
| --- | --- | --- | --- |
| 64px 판독성 | 새싹·후드·눈·몸 분리 유지 | 유색 윤곽선으로 외곽이 더 선명 | 둘 다 콘셉트 비교에 충분. B가 외곽 대비에서 약간 유리 |
| 각도 간 일관성 | 부피와 후드 두께가 이어짐 | 색면과 윤곽이 이어짐 | 두 안 모두 보정 후 3/4가 정면과 구분됨. 정밀 모델 검증은 아님 |
| 표정 구분 | 닫힌/열린 입, 눈썹과 눈꺼풀로 구분 | 초기 중복을 수정함 | 기본+6종을 갖춤. 감정의 의미 전달은 사용자 검증 전 |
| 레이어 분리/리깅 | 부드러운 음영 때문에 수작업 분리 필요 | 명확한 면 경계가 작업에 유리 | 둘 다 단일 래스터. 리깅 가능 파일로 간주할 수 없음 |
| 독자적 정체성 | 기존 눈티 특징과 원화 연속성 강함 | 특징은 유지하고 그림체가 바뀜 | 외부 마스코트를 모방하는 프롬프트를 사용하지 않음. 전수 유사성 조사는 수행하지 않음 |
| 단순함·고급감 | 직물/잔주름을 줄인 통일된 매트 재질 | 단정한 색면, 일부 버클/주름 선은 남음 | 원화 충실도와 재질 정돈을 합치면 A 추천 |

이는 생성 이미지에 대한 시각적 판단이다. 계량화된 사용자 선호 점수, 법적 독창성 보증 또는 실차 적합성 판정이 아니다.

## 수행한 절차

1. 프로젝트의 기본 원화와 참조 사용 위치를 확인했다. 고정 파일의 SHA-256을 기록했다.
2. 원화 참조를 포함한 별도 생성 호출로 A/B를 만들었다.
3. 최초 시트의 3/4 회전 부족, B 배지 곡선과 차분함/안도의 중복을 보정했다.
4. 시트의 픽셀을 그대로 64/128px 전신과 64×64 얼굴 뷰포트로 브라우저 렌더링했다.
5. 투명 정면 파생 PNG 두 장을 생성하고 Pillow로 크기·모드·알파 분포를 읽었다. Pillow로 이미지 내용을 편집하지 않았다.
6. 64px 검토에서 B 안도/기쁨의 열린 입이 비슷해 보여 B 안도를 닫힌 입으로 바꿨다. A/B 호기심에는 비대칭 눈썹과 옆 시선을 보강했다.
7. 최종 A v3/B v4로 비교 보드와 축소 검토 PNG를 다시 렌더링하고 직접 확인했다. 원본·시트·보드 파일은 별도 이름으로 유지했다.

리뷰 담당 에이전트가 별도로 시트와 축소 검토를 확인했다. A를 추천하는 판단이 일치했다. 초기 문제와 최종 수정본을 구분해 기록했다.

## 픽셀 크기와 표시 조건

- 비교 보드 2600×2200, 축소 검토 1200×1050.
- Chrome headless, device scale factor 1, 외부 웹 자원 없이 로컬 HTML/PNG 사용.
- H64/H128은 전신 표시 영역의 높이다. 작은 여백이 있으므로 실제 유색 캐릭터 픽셀 높이는 조금 작다.
- 얼굴 샘플은 64×64 SVG 뷰포트다. 원본 비율을 유지하며 표시한다.
- 원본은 배경과 포즈를 유지했다. 자세와 배경을 통제한 블라인드 비교 실험은 아니다.
- 투명 추출물은 원 시트에서 별도 생성된 파생본이다. 픽셀 보존 배경 제거로 보장하지 않으며, 시트와 미세한 비례·음영 차이가 있다.
- 실루엣은 파생 RGBA 파일에 CSS 검정색 필터를 적용한 표시다. 원 PNG를 덮어쓰지 않았다.

## 알파 검증과 제한

| 파일 | 모드 | 알파 범위 | 완전 투명 픽셀 | 비고 |
| --- | --- | --- | --- | --- |
| A 정면 투명 v1 | RGBA | 0–255 | 956,480 | 배경 투명 확인, 후드 바깥/새싹 주변에 잔여 |
| B 정면 투명 v1 | RGBA | 0–255 | 801,701 | 배경 투명 확인, 손/발 외곽에 잔여 |

내부의 많은 알파 값은 253이며 완전 불투명 255로 고정되지 않았다. 어두운 배경에서 보이는 작은 색점/밝은 테두리가 있어 정식 배포에는 외곽·불투명도 정리가 필요하다. 64/128px 정적 미리보기에서 외형은 확인했지만, 고해상도 제작 자산 완성으로 판정하지 않았다. 시트 두 장은 RGB이며 투명 이미지가 아니다.

## 미검증 사항과 다음 행동

현재 원화에 대한 별도 최종 승인 기록과 라이선스 원문은 미확인이다. 사용자 지정 참조와 생성 이력만 기록했다. 생성 도구의 모델·시드·계정별 비용도 노출되지 않았다.

실차/에뮬레이터의 이번 시안 표시, Figma 대비 UI 검증, 접근성/색 대비의 정량 측정, 메모리·CPU·프레임 성능은 이번 정적 캐릭터 시안 범위에서 수행하지 않았다. 기존 앱 기능과 주행 제한에는 변경이 없다.

다음 행동은 **A 방향 선택 후 제작용 마스터 정리**다. 얼굴 기준점·각도 비율, 배지의 원래 경로선을 정확히 맞추고 레이어를 분리한다. 알파 정리와 밝은/어두운 배경 확인을 마친 정적 자산으로 기존 렌더러에서 검증한다. 그 후 경로·목적지·명시적 기분에 따른 허용 요소만 확장한다.
