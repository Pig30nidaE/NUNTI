# 현대 Gleo AI와 Nunti 적용 범위

확인일: 2026-11-03. 2026 현대자동차그룹 앱 개발 공모전 맥락에서 사용자가 말한 “Gelo AI”를 **Gleo AI(글레오 AI)**로 확인해 조사했다. 동명의 다른 제품은 이 검토에서 제외한다. 공개된 현대자동차그룹 Pleos 공식 문서만 사용했으며 계정 접속, API 호출, 모델 설치, 녹화·녹음은 하지 않았다.

## 확인된 기능과 현재 제약

| 항목 | 공식 문서로 확인한 내용 | Nunti에 대한 판단 |
| --- | --- | --- |
| Gleo Interface | 사용자의 음성 명령을 앱이 등록한 function call로 바꾸고, 앱의 Callback을 받아 최종 답변을 생성한다. | “이번 경로의 동반자 만들어 줘” 같은 앱 실행·조작 진입점으로 검토할 수 있다. 이미지 생성 모델 API로 취급하지 않는다. |
| LLM SDK | 2026-10-19 Playground v2.6.0에서 종료되었고 Gleo Interface 사용을 안내한다. | 과거의 임의 프롬프트용 LLM SDK 예제로 신규 구현하지 않는다. |
| TTS / STT | v3.3.1 문서에 ON_DEVICE, SERVER, HYBRID 모드가 있다. | 차량 내 합성·인식 수단으로 검토할 가치가 있다. 공개 문서와 실제 프로젝트 권한을 따로 확인해야 한다. |
| 이미지 | 검토한 현행 Gleo Interface 계약에서 이미지 업로드·생성·PNG/RGBA 반환용 API를 찾지 못했다. | Gleo만으로 아바타 원화를 생성할 수 있다고 판단할 근거가 없다. 비공개 제공 여부까지 부정하는 결론은 아니다. |

근거: [Gleo Interface](https://document.pleos.ai/en/docs/pleos-only/app-integration-guide/guide/core-concepts), [2026-10-19 LLM SDK 종료 안내](https://document.pleos.ai/en/docs/pleos-only/release-note/playground-release-note), [TextToSpeech 소개](https://document.pleos.ai/en/docs/pleos-only/connect-sdk-pleos/TextToSpeech/intro), [SpeechToText 소개](https://document.pleos.ai/en/api-reference/connect-sdk-pleos/SpeechToText/intro).

## 권한과 키

TTS/STT의 SERVER·HYBRID는 Pleos My Project의 Client ID·Client Secret을 사용한 앱 등록이 필요하다. ON_DEVICE만 사용할 때는 앱 등록과 네트워크가 필요 없다고 명시한다. 이는 차량에 제공되는 엔진을 쓰는 방식이며, 모델 가중치를 내려받아 Nunti 서버나 일반 PC에서 실행할 수 있다는 뜻은 아니다. [TTS 모드·초기화](https://document.pleos.ai/en/docs/pleos-only/connect-sdk-pleos/TextToSpeech/intro), [STT 모드·초기화](https://document.pleos.ai/en/api-reference/connect-sdk-pleos/SpeechToText/intro).

그러나 현재 공개 프로젝트 생성 가이드는 TTS·STT·FusedLocation·Vehicle Control을 **Not Available Yet**으로, NaviHelper·Vehicle State를 **Ready to Use**로 안내한다. 따라서 ON_DEVICE API의 존재만으로 우리 팀이 지금 사용할 수 있다고 보고하면 안 된다. 공모전 참가자에게 따로 제공되는 권한과 Nunti 프로젝트의 실제 상태는 별도 확인 대상이다. [프로젝트 생성 및 SDK 접근 권한](https://document.pleos.ai/en/docs/pleos-only/create-my-project).

TTS에는 `pleos.car.permission.TTS_SERVICE` 권한이 필요하다. Manifest 선언 후에도 실제 권한 상태를 확인해야 한다. [TTS 권한 가이드](https://document.pleos.ai/en/docs/pleos-only/connect-sdk-pleos/TextToSpeech/declaring-permissions).

## Gleo 연동의 구현 경계

앱이 `assets/schema.json`으로 명령을 정의하고 Android Intent를 받아 처리하는 구조다. App Schema에 등록할 수 있는 음성 호출 함수는 최대 3개이며, 전달 인수는 string·number·boolean·array 범위로 설명된다. Schema 검토·승인 후 통합이 활성화된다. 앱에서 임의 JSON이나 이미지 URL을 인수로 다룬다고 해서 Gleo에 이미지 생성 기능이 생기는 것은 아니다. [App Schema 작성](https://document.pleos.ai/en/docs/pleos-only/app-integration-guide/guide/app-capability), [Schema 전달·승인](https://document.pleos.ai/en/docs/pleos-only/app-integration-guide/guide/deliver-schema), [Android 호출 예제](https://document.pleos.ai/en/docs/pleos-only/app-integration-guide/guide/examples).

Callback은 상태·메시지·선택적 결과 데이터를 돌려주고, Gleo가 이를 화면 텍스트나 음성으로 전달한다. Gleo Action은 7초를 넘으면 취소된다. Nunti가 자체 음성을 재생할 때는 Callback의 `mode: "silent"`가 문서상 지원된다. [Callback 계약](https://document.pleos.ai/en/docs/pleos-only/app-integration-guide/guide/action_callback).

따라서 다음은 **Nunti 구현 제안**이다. Gleo 명령을 받으면 실제 내비게이션 목적지와 경로를 확인하고 생성 작업 접수 여부를 7초 안에 반환한다. 시간이 걸리는 이미지 생성은 별도 작업으로 진행하고, 완료 시 앱 안에서 탄생 연출과 아바타를 표시한다. 해당 비동기 흐름과 차량 내 사용 조건은 구현·실기 검증이 필요하다.

## 캐릭터별 음색에 대한 근거 한계

TTS 공개 API 목차에 `setSpeakerType`이 있으므로 “음색 선택이 전혀 없다”고 단정할 수 없다. 다만 확인한 참조 페이지에는 지원 음색·인수·언어별 범위의 설명이 노출되지 않았다. 캐릭터 설명으로 새 음색을 설계하고, 음색 ID를 저장해 후속 대사에서도 재사용하는 API는 확인하지 못했다. 자연스러움과 귀여움도 실제 청취 전에는 판단할 수 없다. [TextToSpeech API 목록](https://document.pleos.ai/en/docs/pleos-only/connect-sdk-pleos/TextToSpeech/text-to-speech/ai.pleos.playground.tts/text-to-speech/entry), [setSpeakerType 참조](https://document.pleos.ai/en/docs/pleos-only/connect-sdk-pleos/TextToSpeech/text-to-speech/ai.pleos.playground.tts/text-to-speech/set-speaker-type).

## Nunti에 적용할 결론

핵심 입력은 사용자가 그린 선이 아니라 **내비게이션이 산출한 목적지·실제 주행 경로·여행 목적**이다. Pleos는 NaviHelper로 목적지 설정과 주행 경로 조회를, Gleo Interface로 앱의 음성 명령 연동을 안내한다. 이를 이미지 생성 공급자와 분리해 설계하는 것이 현재 문서에 맞는다. [Pleos SDK 안내](https://developers.pleos.ai/playground).

Gleo를 검토하지 않고 상용 이미지 API만 필수로 정할 근거는 없다. 반대로 공개 Gleo 문서만으로 이미지 API를 대체할 수 있다고 약속할 근거도 없다. 실제 경로에서 추출한 형상과 여행 특성으로 원화를 생성하는 부분은 로컬 이미지 모델과 상용 이미지 API를 같은 입력·디자인 기준으로 비교한 뒤 결정해야 한다. 이전 Qwen/Sohee 음성 결과에 대한 사용자 거절은 TTS 선호의 근거이며, 로컬 이미지 생성 품질을 검증한 결과가 아니다.

미확인 사항은 공모전 참가자 전용 SDK 권한, Nunti 프로젝트 상태, Gleo Schema 승인 절차의 참가자 예외, 사용량·비용·쿼터, 비공개 이미지 API 유무, `setSpeakerType`의 실제 선택 범위다. 공개 SDK 문서가 있다는 이유로 무료·무제한·즉시 사용 가능하다고 가정하지 않는다.
