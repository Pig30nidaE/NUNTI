# Codex prompt 02 — Journey-driven variations

$nunti-route-variants

저장소의 경로 관련 모델과 Pleos SDK 사용 코드를 분석해서 실제 이용할 수 있는 입력 필드, 앱에서 파생해야 하는 필드, 현재 모의 데이터인 필드를 먼저 분류해줘. `docs/NUNTI_DESIGN_CONTRACT.md`는 제안이므로 실제 코드를 우선 확인해줘.

캐릭터 ID는 하나로 유지하고 여정에 따른 외형 차이는 작은 장식, 파스텔 보조색, 패턴, 표정으로만 표현해줘. 도시/산/바다 × 차분/호기심/모험(사용자 명시 선택) 9개 조합을 비교하는 매트릭스를 작성하고, 동일 입력이면 항상 동일 AvatarSpec을 반환하는 버전·시드 구조를 제안해줘.

필요 산출물: 입력 출처 매트릭스, 매핑 표, 기존 코드와 호환되는 타입 제안, 9종 시안 프롬프트, fallback 시나리오 및 단위 테스트. 외부 이미지 API를 각 주행마다 호출하지 마.
