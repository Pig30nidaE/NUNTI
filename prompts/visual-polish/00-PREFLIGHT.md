# 00 — Verify current implementation / adjust skill rules (minimal work)

현재 저장소가 이미 구현된 눈티 앱이라는 전제에서 시작해.

1. 기존 `AGENTS.md`, 캐릭터 관련 이미지 원본, 현재 스킨 생성 호출부, 기존 화면, 애니메이션 효과 코드를 찾아라. 파일 존재를 추측하지 마라.
2. 읽은 Nunti 4개 스킬 중 아래 충돌만 최소 수정한다.
   - `nunti-birth-motion`: `여정의 빛에서 새 캐릭터가 출현` → `화면에 있던 기본 눈티가 실제 스킨을 장착하며 변신`.
   - `nunti-route-variants`: `모든 기본 실루엣 고정` → `얼굴 정체성 고정, 복장·머리·귀 장식·신발·액세서리 실루엣은 크게 변경 가능`.
   - `nunti-identity`: 오래된 의상·목도리·가방을 절대 불변으로 취급하지 않도록 명시.
   - 주행 안전/개인정보/기능 안정성 원칙은 보존.
3. `docs/NUNTI_VISUAL_POLISH_OVERRIDE.md`를 우선 미술 기준으로 적용한다.
4. 기존 기본 원화가 원본인지 스크린샷인지 확인하고 원본 파일을 활용한다.
5. 현재 생성된 캐릭터가 밋밋/평면적이 된 이유(프롬프트, 모델, 평면 SVG 대체, 원본 손실 등)를 3~5줄로 요약한다.
6. 다음 단계에서 쓸 원본 파일과 렌더링 코드 경로를 확보하고 곧바로 시각 에셋 작업을 시작한다.

이 작업에 장시간 설계보고서·시연 영상·대규모 회귀 테스트를 만들지 마라. 기능을 갈아엎지 마라.

7. `references/uploaded_examples/`의 이전 결과 스크린샷을 실패 사례로 분석하되, 그 캡처를 캐릭터 고화질 원본으로 사용하지 않는다.
