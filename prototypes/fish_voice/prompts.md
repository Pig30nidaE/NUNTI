# 눈티 목소리 프롬프트 모음 (Fish Audio 웹)

2026-11-10 작성. Fish Audio 웹앱에서 눈티 목소리를 설계하고(Voice Design), 고른 목소리로 Drama 3가 대사를 연기하게 할 때 붙여 넣을 프롬프트다.

탈락 기록: ElevenLabs Anna Kim과 Qwen "둥근 미소"는 "너무 성인 여자 목소리"라서, Supertonic3에 피치를 올린 후보는 "기계 같아서" 탈락했다. 그래서 아래 프롬프트는 모두 **성인이 아니라 작은 캐릭터·아이 음색**을 처음부터 설계한다. 실존 인물(성우, 연예인, 아이)의 목소리를 흉내 내라는 지시는 넣지 않는다. Fish Audio 라이선스와 공모전의 제3자 권리 조항 때문이다.

## 0. 캐릭터 설정

Voice Design 지시문과 Drama 3 연기 지시는 모두 이 설정에서 나온다. 출처: [ART-DIRECTION](../../docs/design/avatar-v6/ART-DIRECTION.ko.md), [반투명 동반자 설계](../../docs/design/journey-characters/README.md), [여정 캐릭터 브리프](../../docs/product/journey-character-brief.md), 주행습관 정리 초안(`눈티-주행습관-정리.html`)의 감정·후기 원칙, 앱 대사(`EventSpeaker.kt`, `ClosingMessage.kt`, `TripLifecycle.kt`).

### 정체
- **이름**: 눈티 (Nunti).
- **무엇**: 목적지와 내비게이션 경로에서 태어나는 작은 동반자다. 여정마다 새로 태어나 도착 후 컬렉션에 남는다.
- **생김새**: 손바닥만 하다. 둥글고 말랑한 반투명 몸 안에 은은한 빛이 있다. 얼굴은 불투명하고 눈이 크며 입이 작다. 귀의 기울기와 꼬리 곡선이 그날 경로의 굽이를 닮았다. 그림체는 따뜻한 동화책·구아슈풍이다.
- **자리**: 운전자 옆자리에 같이 타는 동승자다. 운전자를 "친한 사람"으로 대한다.

### 성격
| 특징 | 대사에서 드러나는 모습 |
|---|---|
| 몸으로 느끼는 아이 | 급제동·커브의 쏠림을 작은 몸으로 직접 느끼고 반사적으로 소리를 낸다. ("몸이 확 쏠렸어요!") |
| 조금 겁이 많지만 금방 괜찮아짐 | 놀라도 곧 한숨 쉬고 풀린다. 한 번의 실수로 계속 슬퍼하거나 삐지지 않는다. |
| 가르치지 않고, 탓하지 않음 | 점수를 설명하거나 지시하지 않는다. 자기가 어떤 기분이었는지만 말한다. 벌점·죄책감·잔소리 톤은 없다. |
| 다정한 걱정 | 급한 운전이 이어지면 운전자를 탓하는 대신 "무슨 일 있었어요?" 하고 조심스럽게 묻는다. |
| 호기심과 든든함 | 후진하면 "뒤는 제가 같이 볼게요!"처럼 작지만 거들려고 한다. |
| 칭찬을 아끼지 않음 | 편안하게 달리면 뿌듯해하며 "같이 와서 좋았어요!" 하고 기뻐한다. |
| 솔직함 | 확인하지 못한 건 단정하지 않고 "잘 못 봐서 말씀 못 드려요"라고 미안해한다. |

### 말투
- **존댓말 해요체**가 기본이다. 반말은 놀란 감탄사("깜짝이야!")에서만 튀어나온다.
- 문장이 짧다. 감탄사(꺅, 헉, 우왓, 으아, 휴, 어어어?)가 많고, 말끝을 살짝 올린다.
- 숨소리, 작은 웃음, 한숨 같은 몸 소리가 자연스럽게 섞인다.

### 감정 (앱이 쓰는 다섯 가지)
중립(차분) · 놀람 · 걱정 · 안도 · 기쁨. 걱정과 놀람은 오래 가지 않고 중립·안도로 돌아온다.

### 목소리
- **음색**: 작은 몸에서 나오는 높고 맑은 아이·캐릭터 음색. 둥근 모음, 부드러운 자음.
- **성인 목소리가 아니다**: 성인 여성 화자(탈락한 Anna Kim, Qwen "둥근 미소")나 성인 목소리의 피치만 올린 소리(탈락한 Supertonic3 후처리)는 안 된다.
- **과하지도 않다**: 앵앵거림, 콧소리, 과장된 아기 말투는 피한다.
- **피할 톤**: 뉴스·안내 방송 톤, 속삭임·ASMR, 소리 지르기, 실존 인물(성우·연예인·아이) 흉내.

### 볼륨 다이내믹 (상황별)
| 상황 | 목소리 |
|---|---|
| 평소 (설명, 안내) | 작고 부드럽고 차분하다. 볼륨은 낮은 편. |
| 놀람 (급제동, 급가속, 커브) | **순간적으로 확 커지고 높아진다.** 짧은 비명, 숨 들이켜기. 한두 마디만 크고 바로 내려온다. |
| 안도 | 크게 내쉬는 한숨으로 시작해서 평소보다 더 작고 느려진다. |
| 칭찬, 마무리 | 밝고 들뜨지만, 놀람만큼 크지는 않다. |
| 걱정, 안부 질문 | 가장 작고 조심스럽다. |

놀람이 커 보이려면 평소가 작아야 한다. 그래서 지시문마다 "평소엔 작고, 놀라면 순간 커졌다가 바로 가라앉는다"를 넣었다.

주의: 차 안에서 갑자기 큰 소리를 내면 운전자가 놀란다. "커진다"는 평소보다 확실히 크다는 뜻이지, 소리를 지르라는 뜻이 아니다. 음원을 만든 뒤 가장 큰 반응도 다른 대사와 체감 차이가 과하지 않게 맞춘다.

## 1. 웹에서 하는 순서

1. fish.audio 웹앱에서 **Voice Design**을 연다.
2. 언어를 **한국어(ko)**로 고르고, 아래 2장의 지시문 하나를 넣는다.
3. 미리듣기 문장에는 3장의 문장을 그대로 넣는다. 모든 방향에 같은 문장을 써야 비교가 된다.
4. 후보(최대 4개)를 들어 보고, **평소 문장과 놀람 문장의 차이가 잘 나는지**를 기준으로 고른다. 후보는 `방향-번호`(예: `A-2`)로 메모한다.
5. 저장한 목소리를 고른 뒤 **Text to Speech**에서 모델을 **Drama 3**로 바꾸고, 4장의 대사를 붙여 넣어 들어 본다.

Voice Design은 목소리 자체(음색, 성격, 감정 폭)를 정하고, 대사마다 얼마나 크게 할지는 4장의 Drama 3 지시가 정한다. 둘 다 필요하다.

## 2. Voice Design 지시문 (100자 이내)

Voice Design 지시문은 **100자 제한**이 있어서 0장 설정을 다 넣을 수 없다. 그래서 목소리를 정하는 데 가장 중요한 것만 남겼다: **작은 아이·캐릭터라는 것, 성격 한두 개, 음색, 존댓말, 평소↔놀람 볼륨 차이.** 나머지 성격(가르치지 않음, 다정한 걱정, 솔직함 등)은 4장의 Drama 3 연기 지시로 대사마다 넣는다.

방향마다 한국어판과 영어판이 있다. 한국어판이 글자당 정보가 많아서 성격까지 들어간다. 한국어 지시를 잘 못 알아듣는 것 같으면 영어판을 쓴다(한국어 지시가 먹히는지는 아직 확인하지 않았다). 글자 수는 모두 100자 이하로 확인했다(공백 포함).

### A. 통통 튀는 마스코트
> 가장 귀여운 쪽. 반응이 가장 크다.

한국어 (79자)
```
손바닥만 한 둥근 마스코트 아이. 다정하고 겁이 조금 많음. 통통 튀는 높고 맑은 목소리, 존댓말. 평소엔 작게, 놀라면 순간 크고 높게 꺅.
```
영어 (100자)
```
Tiny round mascot kid, kind and bubbly, high bright voice. Soft when calm, loud squeal when startled
```

### B. 말랑한 인형 친구
> 성별이 드러나지 않는 부드러운 쪽. 평소가 특히 조용해서 반응이 도드라진다.

한국어 (76자)
```
수줍은 말랑 인형 같은 아이, 성별 중립. 부드럽고 달콤한 목소리, 존댓말. 평소엔 조용조용, 놀라면 확 커졌다가 길게 한숨 쉬며 풀림.
```
영어 (100자)
```
Shy plush-toy child, gender-neutral, soft sweet voice. Quiet usually, sudden loud eek when surprised
```

### C. 장난꾸러기 조수
> 감정 폭이 가장 큰 쪽. 놀람과 안도의 대비가 크다.

한국어 (78자)
```
장난꾸러기 꼬마 조수. 반짝이는 아이 목소리, 존댓말. 수다스럽고 칭찬을 잘함. 놀라면 크게 꺅, 안도하면 과장된 한숨. 소리 지르진 않음.
```
영어 (98자)
```
Playful little sidekick kid, sparkly voice. Chatty, loud squeals when startled, big relieved sighs
```

### D. 조그만 요정
> 가볍고 맑은 쪽. 아이보다 "작은 생명체" 느낌. 반응은 높아지는 쪽이 크다.

한국어 (75자)
```
손바닥만 한 다정한 요정. 가볍고 맑은 아이 목소리, 존댓말. 평소엔 잔잔하게, 놀라면 음이 확 올라가며 커졌다가 키득 웃으며 내려옴.
```
영어 (99자)
```
Palm-sized gentle sprite, airy clear childlike voice. Soft, pitch jumps high and loud when startled
```

### E. 꼬마 동승자 (가장 자연스러운 쪽)
> 캐릭터 연기를 줄이고 진짜 어린아이가 옆에 탄 느낌. A~D가 과하게 들리면 쓴다.

한국어 (77자)
```
옆자리에 탄 일곱 살 아이. 연기 없는 자연스러운 목소리, 앵앵거리지 않음. 평소엔 조금 작게, 차가 쏠리면 솔직하게 크게 헉 하고 놀람.
```
영어 (97자)
```
Natural cheerful 7-year-old riding along, not squeaky. Soft talk, honest loud gasp when car jolts
```

조정용 문구 (100자를 넘지 않게, 덧붙이지 말고 **바꿔 넣는다**):
- 성인처럼 나오면 → 맨 앞을 `아주 어린 아이 목소리, 절대 어른 아님.`으로 바꾸고 성격 문장을 뺀다.
- 과하게 앵앵거리면 → `앵앵거리지 않고 아기 말투 아님`을 넣고 `높고`를 뺀다.
- 반응이 안 커지면 → 성격 문장을 빼고 `평소와 놀랄 때 볼륨 차이가 아주 큼`을 넣는다.
- 소리 지르기처럼 들리면 → `놀라도 소리 지르지 않음`을 넣는다.
- 안내 방송처럼 딱딱하면 → `친한 사람에게 수다 떨듯`을 넣는다.

## 3. 미리듣기 문장 (300자 이하)

평소 → 놀람 → 안도 → 놀람 → 칭찬 순서로, 볼륨이 오르내리게 짰다. 첫 문장은 눈티의 해요체 말투로 인사한다.

```
안녕하세요, 저는 눈티예요. 오늘도 같이 천천히 가요. 꺅! 깜짝이야! 심장 떨어지는 줄 알았어요! 휴, 이제 좀 안심돼요. 으아, 커브 너무 빨라요! 오늘 정말 편안했어요. 같이 와서 좋았어요!
```

Voice Design 미리듣기에 대괄호 연기 지시가 먹히는지는 확인하지 않았다. 지시 없이 문장 부호(!)만으로 차이가 나는지 먼저 듣는다.

## 4. Drama 3 대사 대본

괄호 `[ ]` 안은 연기 지시이고 읽히지 않는다. `<forceful>`, `<soft>`, `<fast>`, `<slow>`, `<whisper>`, `<emphasis>`는 감싼 단어에만 적용된다. 문구는 앱의 정해진 문장(`EventSpeaker.kt`, `Model.kt`, `ClosingMessage.kt`, `TripLifecycle.kt`)과 **글자 하나까지 같아야 한다**. 앱이 문장을 기준으로 음원을 찾기 때문이다.

볼륨 단계: **크게**(놀람 첫마디) > **보통 위**(칭찬, 신남) > **보통**(설명) > **작게**(안도 끝, 걱정, 안부).

### 사건 반응 (주행 중, 짧게, 첫마디가 크다) — 모두 녹음 완료, 음원은 저장소의 `mp3/`
| ID | 볼륨 | 대본 |
|---|---|---|
| brake-1 | 크게 → 보통 | `[깜짝 놀라 숨을 확 들이켜며, 갑자기 크게] <forceful>꺅!</forceful> 깜짝이야!` |
| brake-2 | 크게 → 보통 | `[놀라서 크게 외쳤다가 살짝 토라진 듯] <forceful>악!</forceful> 놀랐잖아요!` |
| brake-3 | 크게 → 작게 | `[헉 하고 크게 숨을 삼킨 뒤, 가슴을 쓸어내리며 작아지는 목소리로] <forceful>헉!</forceful> 심장 떨어지는 줄 알았어요!` |
| accel-1 | 크게 | `[몸이 뒤로 젖혀지며 놀라서 크게, 신기한 듯] <forceful>우왓!</forceful> 몸이 확 쏠렸어요!` |
| accel-2 | 크게 → 보통 | `[크게 놀랐다가 살짝 웃으며] <forceful>으악,</forceful> 출발이 엄청 빨랐어요!` |
| curve-1 | 크게 | `[옆으로 쏠리며 갑자기 크게 비명] <forceful>꺄악!</forceful> 커브에서 몸이 확 쏠렸어요!` |
| curve-2 | 크게 → 보통 | `[어지러운 듯 크게 칭얼거리며] <forceful>으아,</forceful> 커브 너무 빨라요!` |
| relief | 크게 내쉬고 → 작게 | `[긴장이 풀려 크게 한숨을 내쉰 뒤, 작고 느리게] 휴, <soft>이제 좀 안심돼요.</soft>` |

급감속은 급제동 대사(brake-1~3)를, 후진 과속은 급가속 대사(accel-1~2)를 같이 쓴다. 따로 녹음하지 않는다.

### 마무리 멘트 (정차 후, 세 부품을 이어 붙인다)

앱([ClosingMessage.kt](../../android/feature/score/src/main/kotlin/ai/nunti/score/ClosingMessage.kt))이 **총평 → 장면 → 안부** 순서로 이어 붙인다. 총평은 최종 점수 구간(90 이상, 80 이상, 70 이상, 그 아래)으로 고르고, 급한 사건이 있으면 한 단계씩 낮춘다. 장면은 그날 가장 많았던 쏠림 사건이나 회복 흐름이고, 해당이 없으면 빠진다. 안부는 아슬아슬했으면 질문, 아니면 인사다.

**녹음 순서**: ★ 표시(각 부품의 1번, 13문장)를 먼저 만든다. 앱은 첫 마무리 멘트에 1번 문구를 쓰므로 ★만 있어도 모든 경우가 한 번씩 소리 난다. 2번 문구(13문장)는 같은 말이 반복되지 않게 하는 변형이라 나중에 만들어도 된다.

#### 총평 (전체 점수)
| ID | 볼륨 | 대본 |
|---|---|---|
| ★ verdict-unknown-1 | 작게 | `[살짝 머쓱하게, 부드럽게] 음, 오늘은 제가 놓친 게 많아서 어땠는지 다 말하긴 어려워요.` |

## 5. 고른 뒤 할 일

- 고른 목소리 ID와 방향(A~E), 바꾼 지시문을 이 파일 아래에 기록한다.
- 음원은 24kHz·모노·16bit WAV로 바꾸고, 앞에 **150~200ms 묵음**을 넣는다 (Pleos 음성 안내 가이드). `LocalVoiceCatalog`의 manifest 규격에 맞춘다.
- 볼륨은 대사마다 따로 정규화하지 않는다. 정규화하면 놀람과 평소의 차이가 사라진다. 대신 **전체를 같은 비율로** 맞추고, 가장 큰 반응이 귀에 거슬리지 않는지만 확인한다.
- 문장을 바꾸면 그 음원도 다시 만들어야 한다.
