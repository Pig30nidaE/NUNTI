# Nunti 여정 MVP 직접 시험하기

이 Mac에서 [Start Nunti MVP.command](Start%20Nunti%20MVP.command)를 Finder에서 더블클릭하거나 터미널에서 다음 명령을 실행한다.

```sh
open "/Users/pig30nidae/NUNTI/prototypes/journey_mvp/Start Nunti MVP.command"
```

기존 Pleos 에뮬레이터를 열고 준비한 Debug APK를 데이터 삭제 없이 설치한다. 이미 실행 중인 같은 AVD가 있으면 재사용한다. 내려받기나 API 연결은 하지 않는다. 화면이 열리면 다음 순서로 시험한다.

1. 왼쪽에서 여행을 고르고 외형·이름·여행 설명을 확인한다.
2. 조용한 시험 환경에서 오른쪽 위 **음성 시험 시작**을 누른다. **인사 듣기**로 같은 캐릭터의 목소리를 듣는다.
3. **도착했어요 → 도착 대사 → 동반자 보관**을 누른다.
4. 다른 여행을 고르며 체형·모티브·목적에 따른 차이를 비교한다. **경로 변경 시험**에서는 같은 동반자를 유지한다.
5. 앱을 닫고 같은 실행 파일로 다시 연다. 선택한 외형·목소리 설정·도착 상태·보관함은 유지하고 자동 발화는 하지 않는다. 음성 시험은 다시 켠다.

**같은 문장**은 모든 캐릭터가 동일한 원문을 읽는 비교 버튼이다. 기존 큐의 60초 반복 제한을 공유하므로 다른 캐릭터로 바꿔도 바로 같은 문장을 반복 재생하지 않는다. 인사와 도착 대사는 케이스별 원문으로 비교할 수 있다. P·속도0·UX 허가를 실제 차량 서비스에서 확인하지 못하거나 백그라운드로 가면 표시·재생을 제한한다. 자동차가 아닌 일반 Android는 차량 허가와 분리한 합성 시험 모드다.

앱 안의 8개는 PC에서 실제 생성한 고정 시험 여정이다. Android는 레시피에서 새 C 방향의 정적 2.5D 외형을 직접 그리고 저장된 TTS를 재생한다. 새 여정의 모델 합성은 아래 PC worker가 담당한다.

준비한 APK·번들 정합성만 확인하거나 로컬 소스에서 재빌드하려면 다음 명령을 사용한다.

```sh
python3.12 scripts/run_journey_mvp.py --check
python3.12 scripts/run_journey_mvp.py --build
```


새 여행을 직접 생성하려면 [PC 입력·생성 가이드](README.md#내-여정-추가)를 따른다. 기존 8개를 다시 생성할 필요 없이 새 여정 JSON 하나를 전달할 수 있다. 모델 합성은 이 Mac에서 실행하고 결과를 APK에 추가한다.

```sh
python3.12 scripts/run_journey_mvp.py --input /절대경로/내-여정.json \
  --label '나의 새 여정' --summary '숲 모티브 · 방문'
```

직접 시험한 느낌은 외형의 귀여움, 보관하고 싶은 정도, 여행과의 연관성, 목소리 자연스러움을 따로 판단한다. 자동 검사는 사용자의 취향이나 운전습관 개선을 판정하지 않는다. Anna는 선호 기준으로 유지하며 이 계정 없는 버전은 Sohee의 연기 변화다.
