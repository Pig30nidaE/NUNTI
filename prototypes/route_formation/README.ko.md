# 경로가 동반자가 되는 세 가지 연출

```sh
python3.12 -m http.server 8781 --bind 127.0.0.1 --directory prototypes/route_formation
```

브라우저에서 http://127.0.0.1:8781/ 을 연다. 같은 8초 시간축에서 A·B·C가 나란히 재생된다. 슬라이더를 움직이면 같은 순간을 비교한다. 경로·변형·형성·완성 버튼은 해당 시간으로 이동하고 멈춘다.

- A는 입력 경로의 점을 실제 알파 너비를 따르는 여러 겹의 리본 위치로 연속 변형한다. 선이 지나간 곳을 브러시 마스크로 칠해 PNG가 드러난다.
- B는 실제 PNG 알파에서 외곽선을 추출한다. 입력 경로를 그 외곽으로 펼친 뒤, 닫힌 윤곽 안에 불규칙한 수채면이 차오른다.
- C는 실제 알파 안에서 입자의 도착점을 고른다. 입자가 입력 경로를 따라 이동한 뒤 길 끝에서 분기하고, 도착한 자리에서 PNG가 응집된다.

원본은 `docs/design/journey-characters/concepts/recipe-coastal-001.png`다. 바이트가 같은 `reference.png` 복사본을 상대 경로로 읽는다. 원본을 편집하지 않는다. 같은 그림을 사용한 연출 비교이며, 경로마다 새로운 이미지를 생성한 결과가 아니다. 네트워크 모델·외부 디자인 도구·다운로드·유료 호출을 사용하지 않는다.

서버는 이 시안 폴더만 loopback에서 제공한다. 앱과 backend는 변경하지 않는다. Canvas의 실제 알파를 읽으므로 file URL 대신 위 로컬 서버를 사용한다.
