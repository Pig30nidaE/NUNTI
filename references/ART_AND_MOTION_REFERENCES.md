# Nunti reference and inspiration list (design principles only)

## Character
1. **Duolingo visual shape language**: https://blog.duolingo.com/shape-language-duolingos-art-style/ — clear silhouette, emotional shape language, playful expressions, small size legibility. **Do not copy Duo**.
2. **Rive / Duolingo character motion**: https://rive.app/use-cases — state-based joyful reactions, secondary motion, subtle mouth/eye reactions. Do not imitate character.
3. **Headspace** (https://www.headspace.com/): soft sculptural visual language, gentle, human-friendly color contrast, emotional warmth. Inspiration only.
4. **Collectible / game skins**: game-like cosmetic outfits with obvious change from base but same character identity, miniature vinyl figurine packaging / display composition. Search examples of `collectible vinyl mascot outfits`, `cute pet character game cosmetic skins`, `character unlock reveal animation`. Never directly copy recognizable copyrighted IP or branded designs.

## Effects
- **Figma Motion export limits**: https://help.figma.com/hc/en-us/articles/41307983648407-Export-animations-from-Figma — Lottie does not carry all shaders; only use when output is suitable.
- **Android Compose animation**: https://developer.android.com/develop/ui/compose/animation/quick-guide — layered transitions / canvas effects and keyframes in current app.
- **Rive for games/apps**: https://rive.app/use-cases — useful for interactive state machines only if already in runtime or pays off without unnecessary migration.
- **GPT Image 2.6 prompting**: https://developers.openai.com/api/docs/guides/image-prompting — reference-guided image edits and targeted change instructions.
- **GPT Image API including GIF**: https://developers.openai.com/api/docs/guides/image-generation — 2–16 frames max for GIF, a prototype/effect source not instant rigged animation.

## Visual quality checklist (keep concise)
- Same eye anchors, blush/face roundness, signature asymmetric sprout, tactile 3D soft-vinyl material.
- Skin differences visible without captions at 100px: full outfit, footwear, headgear, accessories, pose.
- Animation must visibly have clothing/silhouette change in mid-frames, energy particles, magical highlight, delightful settle.
- Intended app UI high contrast, character large enough, no decorative animation while driving.
